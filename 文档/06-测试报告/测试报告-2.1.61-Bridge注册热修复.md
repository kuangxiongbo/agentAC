# 2.1.61 Bridge 注册热修复测试报告

日期：2026-07-22

## 根因

生产 2.1.60 完成迁移 `071` 后，`agents` 唯一键为 `(name, workspace_id)`，但 Bridge 和 Gateway POST 仍使用 `ON CONFLICT(name)`。SQLite 拒绝该冲突目标，Edge Agent 列表无法注册，值守链路不能继续验收。

## 修复与门禁

- Bridge 从 `sync_clients.workspace_id` 解析归属，并事务执行复合键 upsert。
- 中心 inventory 清理与 Bridge 注册共享 Workspace；Gateway POST 同步使用复合键。
- 行为测试覆盖两个 Workspace 同名 Agent 互不覆盖、同 Workspace 更新成功。
- Server 135 files / 1138 tests、Edge 98 files / 994 tests 全部通过。
- 双端 typecheck 与 production build 通过；release surface、standalone/Docker artifact boundary 通过。
- Edge Runtime ZIP SHA-256：`e9c938afcf403e22859c470dd28e2e93376f4b38fb6f165b5d95ef4b03f88e9c`。
- Docker 镜像摘要和生产 Bridge/值守/监督证据待发布后补录。
