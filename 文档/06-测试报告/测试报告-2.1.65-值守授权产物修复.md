# 2.1.65 值守授权产物修复测试报告

## 1. 根因

`2.1.64` 已恢复 Runtime ZIP 交付，Claude 也真实调用了 `mcp__mission_control__mc_create_watch_event`，但中心返回 HTTP 500。生产日志为 `ENOENT: /app/license-schema.json`：安全回迁后的 entitlement 代码需要该文件，Docker Runtime 阶段却没有复制它。

## 2. 修复

- 标准镜像和 runtime-only 镜像都显式复制 `license-schema.json`。
- 产物边界脚本增加强制检查。
- 生产跨架构构建限制为 1 worker / 3 GB Node heap，避免 8 GB Docker VM 出现 OOM；仅影响构建阶段。
- 不修改人工值守判断、回复、目标监督、任务或会话业务代码。

## 3. 验收

- 自动化：Server/Edge 单测、typecheck、build、release surfaces、artifact boundary。
- 镜像：容器内 schema 文件存在，license config 正常。
- 真实链路：Claude MCP 调用、watch event、assist lease/ack/completed、intervention success、Steward 同会话语义回复。

真实生产结果在发布后补录，不预填通过。
