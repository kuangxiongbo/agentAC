# 2.1.62 Edge 原子升级测试报告

日期：2026-07-22

## 根因

2.1.61 已安装用户真实升级时，托盘启动恢复与周期监督可并发进入 Runtime 安装流程。两个线程共享下载、解压和目标目录，后执行线程会删除先执行线程刚安装的 Runtime；旧 `next-server` 仍可短暂从已删除 cwd 提供 2.1.60 服务，但停止后 Edge 无法重新启动，值守 Bridge 随之离线。

## 修复与门禁

- Runtime 安装、启动恢复和周期监督使用同一进程内互斥锁。
- 新包在候选目录完成复制、依赖修复、版本和静态资源校验后再启用。
- 当前 Runtime 先保留为 rollback；启用后复验失败恢复旧目录。
- 健康旧 Runtime 不再在下载和候选校验前删除。
