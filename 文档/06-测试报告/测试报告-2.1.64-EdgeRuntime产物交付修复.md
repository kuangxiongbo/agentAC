# 2.1.64 Edge Runtime 产物交付修复测试报告

## 1. 结论

`2.1.63` 生产清单存在，但 Docker 构建上下文只放行 `2.1.62` ZIP，导致下载 URL 返回 Next.js HTML fallback，托盘按 SHA-256 fail closed 拒绝安装。`2.1.64` 修正版本化白名单，不改人工值守、目标监督、任务、会话同步、本地模式或授权业务逻辑。

生产 `linux/amd64` 首轮跨架构构建因 Docker 8 GB 内存下的默认并行编译被 OOM 终止。构建配置将 Next worker 限制为 2、Node heap 限制为 4 GB；这些参数只在镜像构建阶段生效。

- 本地模式提示和 OpenClaw 网关检测 UI 与基线无差异；无本地网关时显示未连接属于既有真实状态。
