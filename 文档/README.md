# 文档目录说明

本目录用于保存本仓库后续研发过程中产生的全部过程文档，并作为唯一的文档主目录。

## 使用原则

1. 所有需求、设计、测试、任务、状态文档统一放在本目录下，不再新增到业务代码目录内。
2. 所有编码工作遵循“文档先行”流程：先需求，再测试，再设计，再任务，再编码，再测试报告，再状态回写。
3. 每个需求建议使用统一名称前缀，确保相关文档可以按主题快速检索。

## 目录结构

- `00-规范`：研发流程规范、全局 skill 镜像、文档标准。
- `01-PRD`：需求文档。
- `02-测试用例`：基于 PRD 的测试场景与验收用例。
- `03-架构设计`：系统级架构、模块边界、部署关系。
- `04-程序设计`：接口、数据结构、模块实现设计。
- `05-任务拆解`：可执行任务清单、依赖、状态。
- `06-测试报告`：自测结果、命令、环境、问题记录。
- `07-状态跟踪`：需求状态、任务状态、迭代结论。

## 当前需求主题

当前已建立的主需求主题为“通用智能体中枢平台”，后续相关工作默认围绕这一主题更新对应文档。
