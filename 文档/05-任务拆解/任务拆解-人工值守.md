## 5. V1.4 权限决策完成定义

1. 权限请求可创建、查询、决策，并持久化到 SQLite。
2. 决策必须按 `optionId`，不接受普通聊天消息作为状态变更。
3. 非法选项、重复决策、过期请求均被拒绝或转为 `expired`。
4. 值守 Agent 不允许批准 `high` / `critical` 风险。
5. Worker Agent 可通过 MCP 创建请求、等待结果；值守 Agent 通过 MCP/API 选择 option。
6. Gateway 执行审批镜像到权限请求后，平台决策必须回写 Gateway 原审批入口。
7. 服务层单测和 TypeScript 自测通过。
