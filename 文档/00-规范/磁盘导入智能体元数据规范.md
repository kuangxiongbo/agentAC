# 磁盘导入智能体元数据规范

## 1. 目的

为 `~/.agents`、项目本地智能体目录等磁盘导入型智能体定义统一的 metadata 规范，确保系统能够识别其真实智能体类型，而不是落成 `unknown`。

## 2. 适用范围

适用于以下场景：

1. `~/.agents/<agent>/soul.md`
2. `~/.agents/<agent>/AGENT.md`
3. 其它由本地文件系统导入到 Mission Control Client 的智能体定义文件

## 3. 推荐 frontmatter 字段

建议至少包含以下字段：

```yaml
---
name: Local Expert
description: 本地智能体描述
role: developer
framework: claude
model: anthropic/claude-sonnet-4-20250514
---
```

## 4. 字段说明

### 必填推荐

1. `name`
2. `role`
3. `framework`

### 可选推荐

1. `description`
2. `runtime`
3. `model`
4. `provider`
5. `tools`

## 5. framework 取值规范

当前推荐取值：

1. `claude`
2. `codex`
3. `openclaw`
4. `cursor`
5. `opencode`
6. `hermes`
7. `generic`

## 6. 推断规则

系统按以下优先级识别磁盘导入智能体类型：

1. `framework`
2. `runtime`
3. `main_runtime`
4. `provider`
5. `model`

若全部缺失，则落为 `unknown`。

## 7. 示例

### Claude 智能体

```yaml
---
name: Local Expert
description: 本地 Claude 工程智能体
role: developer
framework: claude
model: anthropic/claude-sonnet-4-20250514
---
```

### Codex 智能体

```yaml
---
name: Local Expert
description: 本地 Codex 工程智能体
role: developer
framework: codex
model: openai/codex
---
```

### Hermes 智能体

```yaml
---
name: Local Expert
description: 本地 Hermes 智能体
role: developer
framework: hermes
model: hermes
---
```
