## 2. 干预留痕（关键）

### HW-TC-A01 代发成功留痕

- **前置**：租户已开通；binding 启用；Bridge 在线；规则可命中。
- **步骤**：触发编排代发 → continue 成功。
- **预期**：`human_watch_interventions` 含 `intervention_attempt` + `intervention_completed`（`outcome=success`）；`prompt_preview` 非空；`fingerprint` 一致。

### HW-TC-A02 代发失败留痕

- **前置**：模拟 Bridge continue 返回错误。
- **预期**：`intervention_completed` 且 `outcome=failed`；`error_message` 有值；**无** success 记录。

### HW-TC-A03 指纹去重跳过留痕

- **前置**：同 fingerprint 已成功代发过一次。
- **预期**：`intervention_skipped`，`reason=fingerprint_duplicate`；不发起第二次 continue。

### HW-TC-A04 Bridge 离线跳过留痕

- **前置**：client 离线。
- **预期**：`intervention_skipped`，`reason=bridge_offline`；无 `intervention_completed` success。

### HW-TC-A05 查询 API 租户隔离

- **步骤**：租户 A 写入；租户 B 调用 `GET /api/human-watch/interventions`。
- **预期**：B 看不到 A 记录。

### HW-TC-A06 Worker 详情 UI

- **步骤**：打开 Worker 详情「干预记录」。
- **预期**：最近 20 条倒序；含时间、结果、规则摘要。

## 3. 功能（摘要）
