## 3. 详细用例

### TC-001 Claude 主智能体识别

- 前置条件：本机已安装 Claude CLI 或存在其配置痕迹。
- 步骤：调用运行时检测接口并刷新 Agent 列表。
- 预期：Claude 被识别为已安装主智能体，并出现在顶层 Agent 分组中。

### TC-002 Codex 主智能体识别

- 前置条件：本机已安装 Codex CLI。
- 步骤：调用运行时检测接口并刷新 Agent 列表。
- 预期：Codex 被识别为已安装主智能体。

### TC-003 OpenClaw 主智能体识别

- 前置条件：本机存在 OpenClaw 配置或二进制。
- 步骤：调用运行时检测接口并刷新 Agent 列表。
- 预期：OpenClaw 被识别为已安装主智能体。

### TC-004 Hermes 主智能体识别

- 前置条件：本机安装 Hermes。
- 步骤：调用运行时检测接口并刷新 Agent 列表。
- 预期：Hermes 被识别为已安装主智能体。

### TC-005 Cursor 主智能体识别

- 前置条件：本机安装 Cursor 或存在其应用痕迹。
- 步骤：调用运行时检测接口并刷新 Agent 列表。
- 预期：Cursor 被识别为已安装主智能体。

### TC-006 OpenCode 主智能体识别

- 前置条件：本机安装 OpenCode 或存在其配置痕迹。
- 步骤：调用运行时检测接口并刷新 Agent 列表。
- 预期：OpenCode 被识别为已安装主智能体。

### TC-007 主智能体顶层 Agent 同步

- 前置条件：至少识别出两类主智能体。
- 步骤：
  1. 执行主智能体同步。
  2. 读取 `/api/agents`。
- 预期：
  1. 主智能体记录存在。
  2. 主智能体为顶层节点。
  3. 主智能体具备正确 framework。

### TC-008 创建向导受控选择

- 前置条件：系统只识别出部分主智能体。
- 步骤：
  1. 打开创建向导。
  2. 查看第一步可选项。
- 预期：
  1. 仅识别出的主智能体类型可选。
  2. 未识别类型不出现或不可选。

### TC-009 主智能体安装入口

- 前置条件：存在支持安装的主智能体运行时。
- 步骤：
  1. 在运行时管理入口执行安装。
  2. 等待安装任务完成。
  3. 刷新主智能体列表。
- 预期：
  1. 安装动作可触发。
  2. 安装后检测状态刷新。
  3. 对应主智能体可见并可用于后续控制。

### TC-010 子智能体挂载

- 前置条件：存在至少一个主智能体。
- 步骤：
  1. 基于已识别主智能体创建子智能体。
  2. 返回 Agent 面板查看。
- 预期：
  1. 子智能体记录写入成功。
  2. 子智能体挂在对应主智能体下方。

### TC-011 主智能体作为任务目标

- 前置条件：存在主智能体或其子智能体。
- 步骤：
  1. 创建任务并指派给主智能体或子智能体。
  2. 进入任务面板查看。
- 预期：
  1. 任务可正常指派。
  2. 主智能体与子智能体均可进入现有任务管控链路。

### TC-012 聊天页主智能体分组

- 前置条件：本地存在 Claude/Codex/Hermes/OpenClaw 会话。
- 步骤：
  1. 打开聊天页。
  2. 查看侧边栏分组。
- 预期：
  1. 会话按主智能体类型分组。
  2. 每个会话位于正确分组下。

### TC-013 会话交互回归

- 前置条件：存在至少一个本地会话。
- 步骤：
  1. 打开会话。
  2. 查看 transcript。
  3. 重命名会话。
  4. 设置颜色。
  5. 继续会话。
- 预期：
  1. transcript 正常显示。
  2. 重命名与颜色保存正常。
  3. 继续会话接口不受分组改造影响。
