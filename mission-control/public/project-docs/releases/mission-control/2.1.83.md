# 2.1.83 - Offline Work Projection Continuity

Date: 2026-07-27

## Changes

- Persists the latest successful bounded Work task and activity snapshots per Workspace and Edge client.
- Keeps task board, Dashboard, activity feed, search and standup useful during disconnects or RPC timeouts.
- Labels fallback facts as `local_snapshot` with `stale=true`, `snapshot_at` and `local_live=false`; stale tasks are read-only.
- Replaces stale facts immediately after a successful reconnect and never fabricates data for old clients without a prior compatible snapshot.

## Data And Compatibility

- Migration `074_work_projection_snapshots` adds a rebuildable display-cache table; no local Runtime schema change is required.
- Snapshots are Workspace scoped, limited to 4MiB each and retained for at most seven days.
- Existing cloud control records and live `local_runtime` behavior are unchanged.
