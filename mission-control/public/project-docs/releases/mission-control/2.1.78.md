# 2.1.78 - Work Agent Metrics Projection

Date: 2026-07-24

## Changes

- Projects Work Agent diagnostics, attribution, evaluations, token usage, and costs from the authoritative Edge Runtime into Center views.
- Adds aggregate evaluation responses for the Security Audit page when no Agent filter is supplied.
- Implements the existing `session-costs` UI contract and aligns all cost views to one normalized token record source.

## API And Architecture

- Adds read-only `agent_metrics_request/response` Bridge messages for `diagnostics`, `attribution`, `evals`, and `tokens`.
- Edge token records are merged in memory and are not persisted to the Center database.
- Offline Work diagnostics/attribution return `503` instead of misleading empty cloud metrics. Cloud human-watch metrics remain available.
- No database migration or configuration change is required.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.78`; native Tray remains `3.0.10`.
- Installed trays obtain Runtime `2.1.78` from the Center runtime manifest.
- Roll back Center and Runtime together to `2.1.77`.

## Verification

- Center full suite: `1163/1163`; Edge full suite: `1006/1006`.
- Center focused routes: `6/6`; Edge Bridge protocol: `9/9`; both typechecks passed.
- Production builds, clean Runtime startup, release surfaces, image publication, and production comparison remain release gates.

## Gray Release Risk

- Metric projection requires an online Edge advertising `agent_metrics`; older Edge versions continue to show cloud-owned metrics only.
- Token snapshots can be larger than other Bridge messages on installations with long session history; the current local loader remains capped by its existing database and source limits.
