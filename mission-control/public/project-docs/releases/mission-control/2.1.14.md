# AgentCenter 2.1.14 Release Notes

Date: 2026-06-19

## Changes

- Publishes the human-watch event loop as a production release: worker wait states, permission requests, and transcript-rule detections now create structured `human_watch_events` records.
- Adds `/api/human-watch/events` and `/api/human-watch/events/:id/action` so the platform can send messages back to Worker sessions, approve/deny linked permission requests, dismiss events, and write a single audit trail.
- Adds SSE-driven event updates and dedicated watch-event panels in the global human-watch page plus worker/steward bind tabs.
- Changes the rule path to event-first behavior: transcript detection now creates visible watch events before any recovery action, instead of relying on silent auto-send.
- Fixes the front-end event store merge behavior so multiple panels and filters no longer clear or overwrite unrelated pending watch items.
- Publishes Edge Web runtime `2.1.14`; tray native app remains `3.0.6`.

## Upgrade Notes

- Installed users do not need a new tray native build for this release; tray remains `3.0.6`.
- Installed users must receive the new runtime manifest `2.1.14` from the upgraded server image so the tray can replace the local Web runtime and expose the new human-watch event loop.
- If a host still runs the old local runtime after deployment, restart the tray once so it re-fetches the runtime manifest and refreshes the installed runtime.
