# E-AgentCenter 2.1.19

Date: 2026-07-05

## Highlights

- Adds reliable Edge mailbox delivery for human-watch assist, remote session continue, and permission decision relay.
- Adds center-side `edge_messages` / `edge_message_events` state tracking with lease, ack, fail retry, dead-letter, cancel, idempotency, and serial-session guards.
- Adds local Edge mailbox inbox/outbox recovery, idempotent execution records, and same-session serial execution.
- Updates `mc_create_watch_event` so prompt-only human-watch requests default to `delivery_mode=auto` and return queued message tracking when Edge is offline.
- Adds tray mailbox status/drain actions and automatic drain after local runtime recovery, Bridge welcome, and periodic health checks.
- Adds a human-watch Reliable Message Queue panel for pending, leased, retryable, and dead-letter messages.

## Operations

- Default rollback path: leave `MC_RELIABLE_EDGE_MESSAGES` unset. Legacy synchronous Bridge RPC remains the default for `/api/human-watch/assist` unless callers explicitly opt into `delivery_mode=auto|queue` or `queue_if_offline=true`.
- Server image contents: includes center database migrations `067_edge_messages` and `068_human_watch_intervention_message_trace`, reliable message APIs, human-watch queued assist, mailbox status UI, updated MCP scripts, and synced project documentation.
- Edge runtime/tray artifacts: release embeds the `2.1.19` Edge runtime manifest and the current tray manifest after artifact sync; installed Edge/tray clients should update runtime before relying on queued assist execution.
- Upgrade path: deploy the `agentcenter:2.1.19` image, keep `latest` aligned, run the service with existing persistent data volume, and enable `MC_RELIABLE_EDGE_MESSAGES=1` only for gray clients after confirming they advertise `reliable_mailbox`.
- Rollback path: redeploy `2.1.18` or unset `MC_RELIABLE_EDGE_MESSAGES`; queued messages remain auditable in `edge_messages` but legacy synchronous Bridge RPC resumes for callers that do not request queued delivery.
- Runbook: `docs/human-watch-reliable-mailbox-runbook.md`.
