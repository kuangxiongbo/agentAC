# 2.1.69 - Bounded Goal Worker Runtime

Date: 2026-07-23

## Changes

- Gives Goal Worker dispatch, correction, and retry messages a 30-minute execution timeout instead of the ordinary 3-minute continuation default.
- Keeps reliable messages in `processing` until the CLI really returns; timeout and execution errors still produce a failed message rather than a false completion.
- Requires Edge clients to clamp remote timeout values to 10 seconds through 2 hours so a bad server value cannot create unbounded local work.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.69`; native Tray remains `3.0.10`.
- Installed users only need Runtime `2.1.69`; no native Tray reinstall or database migration is required.
- Roll back the Center image and Runtime to `2.1.68`; preserve Center and Edge SQLite files before retrying a historical Goal task.

## Verification

- Supervision dispatch/correction tests: 7 passed.
- Edge reliable mailbox tests: 3 passed, including the 2-hour clamp.
- Server and Edge TypeScript checks passed under the packaged Node 22 runtime.
- Production acceptance requires a complex Worker turn to remain `processing` past 3 minutes, add a new transcript turn, and complete or fail only after the CLI returns.

## Gray Release Risk

- Historical tasks already failed by the old 3-minute limit are not retried automatically; retry one task at a time after both Center and Edge report `2.1.69`.
