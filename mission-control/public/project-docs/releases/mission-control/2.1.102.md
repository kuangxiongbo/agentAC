# 2.1.102 - Select Steward When Creating Goals

Date: 2026-08-07

## Changes

- Lists synchronized human-watch steward Agents through `GET /api/human-watch/stewards`.
- Lets the goal creation dialog select a steward directly by client and local Agent ID.
- Removes the incorrect dependency on enabled Worker-to-steward bindings.
- Shows when the steward's Edge client is offline.

## Upgrade

- Upgrade Center and Edge Runtime to 2.1.102. Tray remains 3.0.10.
- No database migration or configuration change is required.

## Verification

- Center TypeScript validation passed.
- Supervision goal, human-watch binding, and entitlement tests passed 8/8.
- Production verification must confirm Agent 7 appears even when all Worker bindings are disabled and that a goal can be created with it.

## Rollback And Risk

- Roll back Center and Edge Runtime to 2.1.101; no database restore is required.
- Offline stewards remain selectable so operators can prepare goals, but dispatch waits for the Edge client to reconnect.
