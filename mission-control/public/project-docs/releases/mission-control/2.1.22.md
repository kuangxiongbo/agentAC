# E-AgentCenter 2.1.22

Date: 2026-07-06

## Changes

- Adds a hard Edge runtime packaging gate: runtime zips must be built with Node ABI 127, matching the installed tray Node 22 runtime.
- Rebuilds the Edge runtime artifact after the 2.1.21 identity fix so installed clients can load `better-sqlite3` under the tray runtime.
- Server image contents: embeds Edge runtime `2.1.22`, the 2.1.21 client-id stability fix, the 2.1.20 human-watch steward judge auto-provision fix, refreshed project docs, and release manifests.
- API/data/config changes: no database migration or public API contract change. The Edge runtime manifest now advertises `/edge-runtime/client-runtime-2.1.22-darwin-aarch64.zip`.

## Upgrade Notes

- Deploy `agentcenter:2.1.22` and keep `latest` aligned.
- Installed Edge/tray clients should fetch runtime `2.1.22` after the center manifest is live. This is required for installed users whose tray Node runtime is Node 22.
- Do not build or rebuild runtime artifacts on the production host; build locally with Node 22 and publish through the image.

## Known Risks

- The production host is memory constrained. Keep the configured swap and container memory limits; do not perform Docker builds on the host.
- Tray automatic runtime update must be revalidated after production manifest points to `2.1.22`; before that, local tray can still fetch the current production `2.1.21` manifest.
