# AgentCenter 2.0.5 Release Notes

Release date: 2026-06-13

## What Changed

- Added a required release surface verification gate: `pnpm run verify:release-surfaces`.
- The gate validates server, Edge web, tray, Tauri, download manifests, release docs, master docs, package checksums, and local web static chunks before image publishing.
- Release flow now blocks images that advertise a client version without matching runtime/tray artifacts.

## Included Artifacts

- Server image: `crpi-c9b9bml2ajb23n5d.cn-shenzhen.personal.cr.aliyuncs.com/1sheng/agentcenter:2.0.5`
- Edge runtime zip: `/edge-runtime/client-runtime-2.0.5-darwin-aarch64.zip`
- Tray DMG: `/edge-tray/e-agent-edge-2.0.5-darwin-aarch64.dmg`
- Project docs snapshot: `/project-docs/manifest.json`

## Upgrade Notes

- Production should pull the new server image and recreate the container.
- Installed tray clients should detect the new tray manifest when pointed at the updated server.
- Operators should verify `/edge/download` shows 2.0.5 and that downloaded packages match the manifest.

## Verification

Required before publishing:

```bash
pnpm run verify:release-surfaces
pnpm run typecheck
pnpm exec vitest run src/lib/__tests__/effective-license.test.ts src/lib/__tests__/permission-requests.test.ts src/lib/__tests__/permission-request-exec-bridge.test.ts src/lib/__tests__/codex-mcp-injection.test.ts
```

## Rollback

Redeploy `agentcenter:2.0.4` if runtime, tray, or server behavior regresses.

## Known Risks

- This release is still packaged as macOS darwin-aarch64 for Edge runtime and tray artifacts.
- Automatic tray replacement behavior depends on the installed tray client's update polling and operator rollout policy.
