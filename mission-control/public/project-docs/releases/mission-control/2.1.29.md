# E-AgentCenter 2.1.29

Date: 2026-07-06

## Changes

- Fixes Bridge agent status sync so manual or legacy status pushes no longer clear `framework`, `parent_id`, or `session_key` in the center `sync_agent_index`.
- Updates center and Edge `status_push` endpoints to send full local Agent metadata.
- Keeps human-watch Worker session resolution stable after status refreshes, preventing `no_session_kind` skips when the Worker is actually bound to a Codex session.
- Server image contents: embeds Edge runtime `2.1.29`; tray native version remains `3.0.7`.
- API/data/config changes: no schema migration. `agent_status` remains backward compatible; optional metadata is preserved when omitted.
