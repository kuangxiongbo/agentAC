# 2.1.100 - Steward Judge Session Recovery

Date: 2026-08-07

## Changes

- Recovers a human-watch steward when its bound Codex or Claude CLI session resumes without an assistant reply.
- Invalidates the stale dedicated-session binding, provisions a replacement session, and retries the same judge prompt once.
- Keeps the retry bounded; a second empty reply remains an explicit error for human escalation.

## Upgrade

- Upgrade Center and Edge Runtime to 2.1.100. Tray remains 3.0.10.
- Installed Edge clients receive the replacement Web Runtime through the existing tray update flow.
- No database migration or configuration change is required.

## Verification

- Human-watch Judge and local-session focused tests: 28/28 passed.
- Edge TypeScript validation passed.
- Production baseline: three goals completed with Worker MCP evidence and independent steward acceptance using the healthy Claude steward.
- Default Codex steward regression is required after the 2.1.100 Edge Runtime is installed.

## Rollback And Risk

- Roll back Center and Edge Runtime to 2.1.99; no database restore is required.
- Reprovisioning occurs only after an empty Judge reply and only once per request.
