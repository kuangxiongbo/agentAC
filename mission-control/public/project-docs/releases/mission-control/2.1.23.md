# E-AgentCenter 2.1.23

Date: 2026-07-06

## Changes

- Fixes installed Edge client identity repair: when `~/.e-agent-edge/config.json` has a stable `mc-edge-*` `device_id`, the local runtime now reconciles stale DB `settings.device.client_id` before mailbox, gateway sync, and remote bridge use it.
- Prevents historical drifted ids such as a rehashed `mc-edge-*` value from detaching human-watch bindings after restart.
- Server image contents: embeds Edge runtime `2.1.23`, the 2.1.22 Node 22 ABI packaging guard, the 2.1.21 bootstrap identity fix, and the 2.1.20 human-watch steward judge auto-provision fix.
- API/data/config changes: no schema migration. Runtime startup can update the local Edge settings row `device.client_id` from tray config.

## Upgrade Notes

- Deploy `agentcenter:2.1.23` and keep `latest` aligned.
- Installed Edge/tray clients should fetch runtime `2.1.23`; no tray DMG update is required.
- Existing clients with correct `config.json.device_id` will repair stale runtime DB identity automatically.
