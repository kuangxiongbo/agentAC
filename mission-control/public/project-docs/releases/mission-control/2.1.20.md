# E-AgentCenter 2.1.20

Date: 2026-07-05

## Highlights

- Fixes the production human-watch assist path where a historical steward agent without `session_key` caused queued mailbox execution to fail with `Steward has no dedicated judge session yet`.
- Keeps reliable mailbox delivery enabled, but lets the Edge runtime auto-provision or re-provision the steward's dedicated judge session before writing the steward reply back to the Worker session.
- Adds Edge runtime packaging checks that rebuild and verify `better-sqlite3` against the Node runtime used by installed clients, preventing a bad native ABI bundle from shipping.

## Operations

- Server image contents: includes the 2.1.20 Edge runtime artifact, the human-watch judge auto-provision fix, packaging ABI verification, release docs, and synced project docs.
- Upgrade path: deploy `agentcenter:2.1.20` and keep `latest` aligned. Installed Edge clients should fetch runtime `2.1.20` from the center manifest.
- Rollback path: redeploy `2.1.19` or disable `MC_RELIABLE_EDGE_MESSAGES`; note that 2.1.19 can still fail queued human-watch assist for steward agents that lack a dedicated judge session.
