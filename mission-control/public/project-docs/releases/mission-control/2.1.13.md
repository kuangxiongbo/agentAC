# AgentCenter 2.1.13 Release Notes

Date: 2026-06-17

## Changes

- Fixes the remaining stale-process case on macOS by upgrading tray shutdown from a single-child kill to a process-group kill. This targets the full `caffeinate + node/next-server` tree instead of leaving orphaned runtime processes behind.
- Keeps the port-level fallback recovery path after shutdown so any remaining owned `5101` listeners under `~/.e-agent-edge/runtime` are reclaimed before restart.
- Preserves the explicit “other software owns port 5101” diagnostic path without auto-killing unrelated processes.
- Publishes Edge Web runtime `2.1.13` and tray native app `3.0.6`.

## Upgrade Notes

- Installed users must update the tray app to `3.0.6` to receive the process-group shutdown fix.
- After deploying the new service image, runtime manifest `2.1.13` should be visible and the tray can replace and restart the local Web runtime without leaving the old `2.1.9/2.1.10/2.1.12` process tree behind.
