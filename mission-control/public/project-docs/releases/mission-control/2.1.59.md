# 2.1.59 - Human Watch Auto-stop Restart Window

Date: 2026-07-17

## Changes

- Re-enabling or updating a Human Watch binding now starts a fresh `auto_stop.max_runtime_seconds` window.
- Existing bindings no longer auto-disable immediately because their original `created_at` is older than the configured runtime.
- Historical `auto_stop` intervention records remain unchanged for audit.

## Production Evidence

- Binding 4 for Claude Worker 8 and steward Agent 9 was correctly configured with `claude-code` and `auto_send`, but repeated auto-stop records at 23:43, 23:46, and 23:48 disabled it before the test question could be handled.
- The regression test uses an old `created_at` and a fresh `updated_at`, then confirms evaluation reads the transcript and leaves the binding enabled.
