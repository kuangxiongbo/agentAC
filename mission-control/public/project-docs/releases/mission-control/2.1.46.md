# 2.1.46 - Supervised Worker Center Completion

Date: 2026-07-15

## User / Operator Changes

- Managed Workers can read authoritative center Goal tasks/events through MCP instead of relying on the Edge-local task database.
- A Worker can submit structured outcome, resolution, and evidence through a center-validated completion API; identity is injected by the managed process and only the assigned Worker and session are accepted.
- Server and Edge task queue polling now exclude supervised Goal tasks from current-task lookup, capacity counting, and atomic claiming.
- Worker prompts explicitly require `mc_get_supervision_goal` before execution and `mc_complete_supervision_task` before claiming completion.
