# 2.1.99 - Live Dispatch And Central Memory Boundaries

Date: 2026-08-03

## Changes

- Requires a live Edge Bridge WebSocket before a supervised task can match or dispatch to a Worker.
- Stops treating a recent sync heartbeat as a substitute for a deliverable Bridge connection.
- Prevents Center mode from scanning local OpenClaw memory paths, eliminating repeated missing-directory errors.

## Upgrade

- Upgrade Center and Edge Runtime to 2.1.99. Tray remains 3.0.10.
- No database migration or configuration change is required.

- Release surfaces, image manifest, and production checks remain release gates.

## Rollback And Risk

- Roll back Compose to 2.1.98; no database restore is required for these stateless changes.
- A disconnected Edge now remains intentionally ineligible until its Bridge WebSocket reconnects, even if its last sync heartbeat is recent.
- Local Edge mode continues to use its configured OpenClaw memory path; only Center mode disables that filesystem root.
