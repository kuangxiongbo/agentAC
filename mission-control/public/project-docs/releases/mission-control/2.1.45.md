# 2.1.45 - Cross-Runtime Supervision Isolation

Date: 2026-07-15

## User / Operator Changes

- Supervised Goal tasks are isolated from legacy scheduling in both the central server and embedded Edge runtime.
- A live Bridge connection is authoritative for resumable Worker reachability, so a stale offline agent index no longer blocks an active Goal.
- The supervision monitor now invokes Goal Dispatcher on each leased cycle and automatically activates dependency-ready successor tasks.

## Production Evidence

- Goal `f4ea59ee-2e40-48af-8cd5-4bc0f67d4943` proved that 2.1.44 delivered task 9 to Worker 6, but Edge legacy scheduling auto-routed tasks 10 and 11 at activity IDs 104 and 105 and later failed them with `spawn openclaw ENOENT`.
- The same Goal produced `worker_offline_detected` while the Edge Bridge was online because the monitor trusted stale `sync_agent_index.status=offline`.
- This failed Goal remains retained as audit evidence and is not counted as a successful closure.
