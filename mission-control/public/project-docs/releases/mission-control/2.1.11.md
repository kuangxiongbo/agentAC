# AgentCenter 2.1.11 Release Notes

Date: 2026-06-17

## Changes

- Updates the Edge download page and `/api/edge/download-info` so tray installers are shown by chip family instead of a single generic Mac download.
- Adds explicit `Apple Silicon` and `Intel Mac` entries to the download response model. When a platform artifact is not yet published, the UI now shows `暂未提供 / Not available yet` instead of implying one universal installer fits all Macs.
- Keeps runtime/tray update manifests and docs aligned at release version `2.1.11`.

## Upgrade Notes

- Installed users need the service image updated so the new chip-aware download UI and API become visible.
- This release does not yet publish a real `darwin-x86_64` tray DMG or runtime zip. Intel users will see the Intel entry as unavailable until those artifacts are produced and added to the manifests.
