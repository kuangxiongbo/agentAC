# 2.1.49 - Structural Supervision Hold

Date: 2026-07-16

## Changes

- Dependency-waiting supervision tasks now receive an internal hold assignee in the same transaction that creates them.
- Goal Dispatcher releases the hold, rechecks dependencies and worker eligibility, then dispatches or restores the hold before committing.
- Supervision MCP tools expose accurate read-only, non-destructive, idempotent and closed-world annotations for non-interactive Codex execution.

- Retained failed Goal `0bbcfe7f-a4ee-449c-8ccc-f2f4a42253ad` proved the 2.1.48 mailbox injected the temporary MCP server, Worker 6 identity and session identity.
