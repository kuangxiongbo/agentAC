# 2.1.43 - Resumable Supervision Workers

Date: 2026-07-15

## User / Operator Changes

- Goal supervision can resume a dedicated Worker session when its Edge Bridge is online even if the Agent status is offline or sleeping.
- A stale Agent index no longer overrides a live Bridge connection; it reduces match score and remains visible in match reasons.
- Supervised Goal tasks are isolated from the legacy task auto-router.
- Dispatch-blocked events include candidate and rejected-reason diagnostics.

## Production Evidence

- The first 2.1.42 gray Goal generated a real four-task plan and passed human plan approval.
- Dispatch was blocked because runtime-managed main Agents had no session_key and resumable dedicated Workers were marked offline.
- Legacy auto-routing then claimed the supervised inbox tasks and failed with spawn openclaw ENOENT. The failed Goal remains retained as audit evidence.
