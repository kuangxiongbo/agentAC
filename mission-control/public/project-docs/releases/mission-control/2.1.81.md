# 2.1.81 - Bridge Connection Supersession

Date: 2026-07-27

## Changes

- Keeps exactly one current Bridge connection per Edge client ID.
- Closes superseded Center sockets and rejects their pending RPCs explicitly.
- Prevents a delayed old Edge socket close from clearing the replacement connection or scheduling another reconnect.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.81`; native Tray remains `3.0.10`.
- No database migration or configuration change is required. Roll back Center and Runtime together to `2.1.80`.

## Verification

- Connection-focused typechecks, Bridge protocol tests, production builds, clean Runtime startup, release surfaces, and real search/standup RPCs are release gates.

## Gray Release Risk

- A pending request on a superseded socket fails immediately and may be retried by the caller; it is never silently transferred between connections.
