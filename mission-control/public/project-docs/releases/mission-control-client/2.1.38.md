# 2.1.38 - Edge Bridge Bootstrap Reconnect Guard

Date: 2026-07-08

## User / Operator Changes

- Stops the Edge runtime from restarting its production Bridge websocket on every tray bootstrap refresh.
- Human Watch center-to-local transcript and continue calls are less likely to time out while the Worker is waiting for user confirmation.
- Reconnect still occurs when the actual Bridge target or identity changes.

## Runtime / Tray Notes

- Edge Web runtime package version: `2.1.38`.
- Native tray version is unchanged.
- Installed Edge runtimes should update to `2.1.38` to get the Bridge stability fix.
