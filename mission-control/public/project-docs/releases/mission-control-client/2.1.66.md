# 2.1.66 - Real-Time Agent Inventory Synchronization

Date: 2026-07-23

## Changes

- Pushes a complete `agent_status` inventory after local Agent create, update, delete, sync and status-change events.
- Expands the existing HTTP gateway-sync trigger to the same Agent lifecycle events.
- Keeps the periodic heartbeat inventory as a fallback when WebSocket delivery is interrupted.

## Upgrade

- Edge Web Runtime updates to `2.1.66`; native Tray remains `3.0.9`.
- Tray `3.0.9` installs the new Runtime through its existing checksum-verified atomic update flow.

## Verification

- Create a local Agent and verify it appears once on the Center without restarting the Tray or Bridge.
- Rename or delete the Agent and verify the Center index converges through the real-time event or the next heartbeat fallback.
