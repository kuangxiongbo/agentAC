# Edge Runtime 2.1.23 Release Notes

Date: 2026-07-06

## Changes

- Repairs stale installed-runtime identity by preferring tray `config.json.device_id` when it is already a stable `mc-edge-*` id.
- Applies the repaired id to mailbox status, mailbox draining, remote bridge hello, and gateway sync registration.
- Imports tray `device_id` into Web settings when `/api/edge/import-tray-config` runs.
- Includes the 2.1.22 Node 22 ABI packaging guard, the 2.1.21 client-id bootstrap preservation fix, and the 2.1.20 steward judge auto-provision fix.

## Upgrade Notes

- Installed tray users only need runtime `2.1.23`; tray app version remains unchanged.
- Runtime install target is `~/.e-agent-edge/runtime`, with `runtime/package.json` version `2.1.23`.
- Clients whose DB still contains a drifted id should self-repair as long as `~/.e-agent-edge/config.json.device_id` contains the intended `mc-edge-*` id.

## Verification

- `resolveLocalClientId` regression test covers repairing DB `device.client_id` from tray config.
- Human-watch mailbox assist regression still passes with steward judge auto-provision.
- Runtime package is built with Node `v22.16.0` ABI `127`.
- Runtime artifact: `client-runtime-2.1.23-darwin-aarch64.zip`.
- SHA-256: `2c22786085bcc93e459013f2e5c354392aba2d5fc50b1b47e7412c2d63e5120f`.

## Rollback

- Repoint the server Edge runtime manifest to `2.1.22`, or roll the server image back to `agentcenter:2.1.22`.

## Known Risks

- If a client's tray `config.json.device_id` is already wrong, the runtime cannot infer the intended binding automatically; that client must be re-enrolled or the config must be corrected.
