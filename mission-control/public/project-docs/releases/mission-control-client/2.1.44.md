# 2.1.44 - Edge Runtime Ownership Recovery

Date: 2026-07-15

## Edge / Tray Changes

- Tray 3.0.8 recognizes an orphan Edge runtime by its absolute runtime-root path even after the old runtime directory has been moved or deleted.
- A stale `next-server` that still owns port 5101 is reclaimed before the new runtime starts; unrelated port owners remain protected.
- Edge Web runtime aligns to 2.1.44.

## Production Evidence

- Restarting tray 3.0.7 while upgrading 2.1.41 to 2.1.43 left the old `next-server` on port 5101.
- Runtime replacement made `canonicalize()` fail for the old working directory, so ownership was misclassified and the new process repeatedly hit `EADDRINUSE`.
- After the old PID was stopped, runtime 2.1.43 installed and reconnected successfully; tray 3.0.8 makes that recovery automatic.

- Installed recovery passes from tray 3.0.7/runtime 2.1.43 while the old runtime PID retains a deleted working directory: tray 3.0.8 automatically reaps the old PID, installs runtime 2.1.44, restores exactly one 5101 listener, serves chat CSS as `text/css`, and reconnects to the center.

## Upgrade

- Install tray 3.0.8 from the center download page. The tray then downloads runtime 2.1.44 and restarts the local service.

## Gray Release Risks

- Existing stale PID files are not trusted as process ownership evidence; port PID and working directory remain authoritative.
- The update must be tested with a running old runtime, not only with a clean installation.
