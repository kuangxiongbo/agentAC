# Edge Client 2.1.3 Release Notes

Date: 2026-06-14

## Changes

- Separates user-scoped Edge enroll token storage from Bridge gateway token storage.
- Sends `x-edge-enroll-token` when local Web checks whether CLI elevation is entitled, allowing the center to validate the real user's subscription.
- Preserves tenant, enterprise slug, and gateway token fields when tray and local Web exchange configuration.
- Keeps tray app version at `3.0.0`; the Web runtime version is `2.1.3`.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.3-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.0-darwin-aarch64.dmg`

## User Flow Validation

The required validation path is production-like:

1. Deploy the service image that advertises runtime `2.1.3`.
2. Download or update the tray from the service center.
3. Launch the installed tray.
4. Let it fetch `/api/releases/edge-runtime-manifest` from the service center.
5. Confirm the installed runtime package version is `2.1.3` and `http://127.0.0.1:5101/chat` loads styled UI assets.
6. Confirm `/api/edge/tray-config` exposes separate `enroll_token` and `gateway_token` values, with token values redacted in logs.
