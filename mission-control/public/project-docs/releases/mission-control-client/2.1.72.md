# 2.1.72 - Local Work Display Snapshots

Date: 2026-07-24

## Changes

- Extends Bridge agent detail with bounded local task, activity and workspace-file snapshots.
- Adds local task-count summaries to Agent inventory updates.
- Keeps local tasks, activity, files and memory authoritative; the Center receives display data only.

## Upgrade

- Native Tray remains `3.0.10` and installs Edge Web Runtime `2.1.72` from the Center manifest.
- Center and Runtime should be upgraded together; no local task/file content is migrated into the cloud database.

## Verification

- TypeScript and production build passed.
- Center contract tests verified live Bridge and offline fallback behavior.

## Gray Release Risk

- Snapshot payloads are bounded to 50 tasks, 50 activities and 256 KiB per workspace file.
