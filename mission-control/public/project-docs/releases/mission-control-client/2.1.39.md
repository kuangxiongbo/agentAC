# 2.1.39 - Edge Bootstrap Identity Guard

Date: 2026-07-08

## User / Operator Changes

- Stops stale tray bootstrap data from overwriting the active Edge `device.client_id` every refresh cycle.
- Prevents the Bridge websocket from being restarted during a Human Watch steward decision when the gateway URL and token are unchanged.
- Web conversations that ask the user to answer and say `确认` are now recognized as Human Watch candidates after the idle window.

## Runtime / Tray Notes

- Edge Web runtime package version: `2.1.39`.
- Native tray version is unchanged.
- Installed Edge clients should update to runtime `2.1.39`; no DMG reinstall is required for this fix.

## Verification

- `pnpm --dir mission-control-client test src/lib/__tests__/edge-bootstrap-settings.test.ts`.
- `NODE_OPTIONS='--max-old-space-size=8192' pnpm --dir mission-control-client run typecheck`.
