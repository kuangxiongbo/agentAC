# Edge Client 2.1.9 Release Notes

Date: 2026-06-16

## Changes

- Fixes local Web `/chat` client-side CSP/runtime issues that could prevent scripts from executing and leave the page without realtime feedback.
- Shows immediate submitted/delivered feedback after sending a prompt into a local or bridged session.
- Continues transcript refresh while waiting for a reply, even when SSE is connected or lifecycle events arrive before transcript content is flushed.
- Includes the `2.1.9` Web runtime. The tray native app remains `3.0.3`.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.9-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.3-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.9`.
2. Existing tray `3.0.3` users should update only the Web runtime automatically.
3. After deployment, installed Web runtime should update from `2.1.8` to `2.1.9`.
