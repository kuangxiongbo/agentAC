# 2.1.82 - Reliable Work Task Writeback

Date: 2026-07-27

## Changes

- Adds the `work.task.mutation.requested` Local Mailbox handler.
- Validates Runtime identity, Workspace, local task ID, mutable fields and `expected_updated_at` before update/delete.
- Applies task and activity changes in one SQLite transaction, then emits ACK; conflicts and invalid requests fail without changing the task.
- Advertises `work_task_writeback` and preserves idempotent execution across restart or duplicate delivery.

## Artifacts And Upgrade

- Edge Web Runtime updates to `2.1.82`; native Tray remains `3.0.10`.
- No local schema or configuration migration is required. The existing Tray update flow performs atomic Runtime replacement.
- Roll back Runtime with Center to `2.1.81` after cancelling incompatible pending mutation messages.

## Verification

- Edge full suite `1011/1011`, focused mailbox/Bridge `20/20`, typecheck, lint and production build passed.

## Gray Release Risk

- The Runtime intentionally rejects stale cloud snapshots. A failed version conflict is not automatically retried because replaying it could overwrite newer local work.
