# Edge Client 2.1.7 Release Notes

Date: 2026-06-15

## Changes

- The tray setup window now shows runtime download progress, byte counts, verification, unzip, replacement, validation, and local Web startup steps.
- Runtime upgrade now fails visibly when the target version cannot be downloaded or installed instead of falling back to an older runtime.
- Local Web version mismatch errors now show readable current and target versions.
- Includes the `2.1.7` Web runtime and tray `3.0.2`.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.7-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.2-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.7`.
2. Existing tray users should update to tray `3.0.2` to receive the startup progress UI.
3. After deployment, installed Web runtime should update from `2.1.6` to `2.1.7`.

## Verification

- `pnpm run typecheck`
- `cargo check` in the tray Tauri project
- Release-surface verification after runtime and tray bundles are synced
