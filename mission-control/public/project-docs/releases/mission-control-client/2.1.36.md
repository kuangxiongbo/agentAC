# 2.1.36 - Human Watch Steward Daily Limit Alignment

Date: 2026-07-08

## User / Operator Changes

- New Human Watch steward agents created from the Edge runtime now default to `60` interventions per `24` hours instead of the legacy `6` limit.
- The local steward rule block no longer exposes intervention budget fields as transcript matching rules; they remain in `binding_defaults` for rate limiting.
- Center 2.1.36 also narrows Human Watch fingerprint dedupe by adding confirmation content hashing, so new Worker confirmation prompts are not hidden as duplicates of old prompts.

## Runtime / Tray Notes

- Edge Web runtime package version: `2.1.36`.
- Native tray version is unchanged.
- Installed Edge runtimes should update to `2.1.36` before creating new Human Watch steward agents.

## Verification

- `pnpm exec vitest run src/lib/__tests__/human-watch-steward.test.ts`.
- `pnpm run typecheck`.
- Center release surface verification checks the embedded Edge runtime manifest and artifact hash.

## Gray Release Risks

- This does not modify already-created local steward agent config rows. If an old steward still has a custom `6` limit, recreate or update that steward config.
