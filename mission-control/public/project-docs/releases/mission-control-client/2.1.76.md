# 2.1.76 - Edge Work Activity Snapshot Runtime

Date: 2026-07-24

## Changes

- Advertises the Bridge `activity_snapshot` capability and returns bounded local activity plus Claude, Codex, and Hermes session milestones.
- Parses activity data before transport and includes structured session identity, status, model, workspace, and latest prompt metadata.
- Throttles local activity and transcript invalidation to one message per second during sustained output; invalidation messages contain no activity body.

## Upgrade

- Native Tray remains `3.0.10` and installs Runtime `2.1.76` from the Center manifest.
- No local database migration or user configuration change is required.
- Roll back the Runtime and Center together to `2.1.75`.

## Verification

- TypeScript and all `1002/1002` Edge tests passed, including protocol-level activity and session snapshot coverage.
- Production build passed. Packaged Runtime clean startup and production Bridge validation remain release gates.

## Gray Release Risk

- Each snapshot returns at most 1000 combined milestones and reports `truncated=true` above that limit.
- Live activity projection requires an online `2.1.76` Runtime; older or disconnected clients continue to show cloud control activity only.
