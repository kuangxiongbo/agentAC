# Edge Runtime 2.1.24 Release Notes

Date: 2026-07-06

## Changes

- Keeps the Edge runtime package version aligned with the 2.1.24 center release.
- No Edge runtime behavior change is required for the human-watch awaiting-user rule refinement; the steward execution path remains the 2.1.23 runtime path.

## Upgrade Notes

- Installed tray users only need runtime `2.1.24`; tray app version remains unchanged.
- Runtime install target is `~/.e-agent-edge/runtime`, with `runtime/package.json` version `2.1.24`.

## Verification

- Runtime package must be built with Node `v22.x` ABI `127`.
- Server-side human-watch rule tests passed for the awaiting-user fingerprint refinement.

## Rollback

- Repoint the server Edge runtime manifest to `2.1.23`, or roll the server image back to `agentcenter:2.1.23`.

## Known Risks

- If an installed client cannot download the runtime because of network TLS/proxy constraints, the tray may need a restart or manual runtime refresh in small-scope validation environments.
