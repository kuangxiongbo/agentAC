# Edge Client 2.1.5 Release Notes

Date: 2026-06-14

## Changes

- Fixes the local chat UI state where a Codex session could show a completed reply in the transcript API but the page still appeared to be waiting or kept the send button unavailable.
- After submitting a local session prompt, the input is cleared and the send control is released once the request is accepted; background reply tracking no longer blocks the next send.
- Adds immediate and short delayed forced transcript refreshes after continue requests.
- Clears waiting indicators when the refreshed transcript contains the current turn's assistant reply.
- Keeps tray app version at `3.0.0`; the Web runtime version is `2.1.5`.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.5-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.0-darwin-aarch64.dmg`

## User Flow Validation

1. Deploy the service image that advertises runtime `2.1.5`.
2. Let an installed tray update the Web runtime from the service manifest.
3. Open `http://127.0.0.1:5101/chat`.
4. Continue an existing Codex session.
5. Confirm the prompt is accepted, the send button becomes available again, and the assistant reply appears after transcript refresh without stale waiting state.
