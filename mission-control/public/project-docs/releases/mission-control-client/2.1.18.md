# Edge Runtime 2.1.18 Release Notes

Date: 2026-07-05

## Changes

- Added local `/api/human-watch/assist` proxy to forward Worker MCP human-watch assist requests to the cloud server.
- Updated `mc_create_watch_event` so prompt-only calls trigger steward assist, while calls with decision `options` continue to create structured permission requests.
- Injected `MC_WORKER_SESSION_ID` and `MC_SESSION_KIND` into platform-managed Codex MCP configuration for continued sessions.
- Added local human-watch tables for Edge Web/tray runtime schema parity.
