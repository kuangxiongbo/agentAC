# Edge Client 2.1.17 Release Notes

Date: 2026-06-21

## Changes

- Runtime package version moves to `2.1.17` to match the central server release and ship the worker-side plumbing for the human-watch closed-loop: codex-cli sessions managed by the platform now get the `mission_control` MCP server injected via `-c mcp_servers.mission_control.*` config args, so workers can call `mc_create_watch_event` / `mc_create_permission_request` / `mc_wait_permission_request` / `mc_record_worker_human_reply` for confirmation flows instead of relying on free-form chat replies.
- Human-watch steward judge/session-binding logic on the edge client received incremental fixes (`human-watch-judge.ts`, `human-watch-steward.ts`, `local-session-executor.ts`, `remote-server-bridge.ts`).
- Tray native app remains `3.0.6`; no new DMG is required for this release.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.17-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.6-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.17` and tray `3.0.6`.
2. Existing installed trays should detect the higher runtime manifest version and replace the local Web runtime automatically.
3. After relaunch, codex-cli workers running in platform-managed dedicated sessions automatically get the `mission_control` MCP server wired in — no manual MCP config changes needed on the operator side.
