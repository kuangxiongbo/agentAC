# Edge Client 2.0.6 Release Notes

Date: 2026-06-13

## Changes

- Aligns Edge web, tray, and server release version to 2.0.6.
- Removes stale 2.0.2/2.0.5 fallback version literals from local runtime provisioning and download surfaces.
- Adds production runtime auto-update behavior to the tray supervisor: installed clients periodically compare local runtime version with the service-center manifest and replace the local Web runtime when a newer bundle is available.

## Artifacts

- Edge runtime zip: `client-runtime-2.0.6-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-2.0.6-darwin-aarch64.dmg`

## Upgrade Notes

- New downloads from the server download page should show 2.0.6.
- Existing users should install the 2.0.6 tray DMG once; after that, routine Web client updates can be delivered by runtime manifest without frequent tray replacement.
