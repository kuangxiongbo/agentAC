# AgentCenter 2.1.10 Release Notes

Date: 2026-06-17

## Changes

- Fixes platform-managed Codex MCP injection so `mcp_servers.mission_control.env` is emitted as a TOML inline table instead of a JSON string. This removes the `expected a map in mcp_servers.mission_control.env` startup failure.
- Aligns local Edge MCP tools with the server MCP tool surface by adding `mc_create_watch_event` and `mc_record_worker_human_reply` to the bundled local `mc-mcp-server.cjs`.
- Improves tray runtime recovery: when port `5101` is occupied by an older E-Agent Edge runtime process, the tray can reclaim that owned process and start the target runtime automatically.
- Treats saved connection address and token as enough to auto-run/update the local Web runtime; installed users should no longer be blocked by `setup_completed=false`.
- Publishes Edge Web runtime `2.1.10` and tray native app `3.0.4`.

## Upgrade Notes

- Existing installed users must deploy the new service image so runtime manifest `2.1.10` and tray manifest `3.0.4` become visible.
- Existing tray `3.0.3` users should install tray `3.0.4` to receive the stale-process auto-recovery fix.
- Existing installed users should then receive local Web runtime `2.1.10` from the updated service manifest after the tray starts.

## Known Risks

- The new tray native fix is required for automatic recovery when an old local runtime process still owns port `5101`; users who stay on tray `3.0.3` may still need manual recovery.
- Human-watch UI still shows the legacy rule-engine configuration path; the new MCP-driven watch flow is not yet the primary productized UI.
