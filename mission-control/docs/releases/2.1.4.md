# AgentCenter 2.1.4 Release Notes

Date: 2026-06-14

## Changes

- Fixes installed Edge local Web failures when opening large Codex history sessions. Codex session list scanning now reads bounded head/tail windows for large JSONL files instead of loading the full file.
- Keeps Codex transcript reads paged by byte cursor, so 300MB+ sessions remain usable without blocking `/api/server-bridge`, `/api/sessions`, or send/continue APIs.
- Cleans Edge runtime packaging so the zip excludes development logs, pid files, `.next/cache`, `.DS_Store`, and macOS resource metadata.
- Publishes Edge Web runtime `2.1.4`; installed users need this higher `client_version` to receive the fix.
- Keeps native tray app version at `3.0.0`; no tray binary update is required for this Web runtime fix.

## Installed User Upgrade

- Existing tray installations must discover runtime `2.1.4` from the deployed service-center `/api/releases/edge-runtime-manifest`.
- Reusing `2.1.3` for changed runtime code would not notify installed users, because the tray compares manifest `client_version` with the installed runtime version.
- Production validation must happen after deploying the new service image and checking the real service-center manifest.

## Verification

- Built Edge runtime package with `EDGE_RUNTIME_PLATFORM=darwin-aarch64 bash mission-control-client/scripts/package-edge-runtime.sh`.
- Verified large Codex session behavior locally: `/api/sessions?refresh=1` completed in about 0.7-0.8s, 368MB transcript page completed in about 0.02-0.21s.
- Verified `/api/server-bridge` returned connected with token-backed bridge configuration.
- Verified `POST /api/sessions/continue` accepted normal and `local_cli_elevated=true` requests.
- `pnpm run verify:release-surfaces` must pass after runtime and docs are synced.

## Rollback

- Roll back the server with the previous image tag and restart Compose/1Panel.
- If Edge runtime `2.1.4` causes issues, publish a newer fixed runtime version; do not reuse the same runtime version for changed code.
