# 2.1.72 - Local Work Display Authority

Date: 2026-07-24

## Changes

- Treats Edge Runtime as the authority for normal Work agent tasks, activity, configuration, workspace files, SOUL and working memory.
- Merges live local Work snapshots with cloud supervision and reliable-message records in Agent detail.
- Adds `/api/agents/{id}/tasks` and a unified `/api/agents/{id}/activity` response with source and local-live metadata.
- Stores only a rebuildable task-count snapshot in `sync_agent_index.task_stats_json` for fleet cards.
- Makes unsupported cloud-side Work edits read-only and hides cloud-runtime tools/models/channels/cron views for remote Work agents.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.72`; native Tray remains `3.0.10`.
- Database migration `073_sync_agent_task_stats_snapshot` adds a nullable display snapshot column.
- Center and Edge Runtime must both be upgraded. Older Edge clients remain compatible but report `local_live=false` for new detail fields.
- Roll back Center and Runtime together to `2.1.71`; the nullable migration column may remain.

## Verification

- TypeScript checks passed for Center and Edge.
- Production builds passed for Center and Edge.
- 11 focused tests passed for Bridge-only identity, workspace isolation, local-live task/activity/files/SOUL/memory display, heartbeat and task-stat snapshots.

## Gray Release Risk

- Global task/activity/dashboard/search/diagnostic projections are not included in this patch and remain tracked follow-up items.
- Local Work resource writes remain read-only from Center until reliable write-back is implemented.
