# 2.1.44 - Supervision Isolation Hardening

Date: 2026-07-15

## User / Operator Changes

- Supervised Goal tasks are excluded from every legacy scheduler phase: auto-route, assigned-task execution, stale requeue, and Aegis review.
- Legacy auto-route uses an atomic metadata guard before assignment, so a supervised task cannot be claimed between selection and update.
- Goal Dispatcher remains the only component allowed to activate tasks carrying `metadata.goal_id`.
