# 2.1.91 - Managed MCP Human Watch Reply

Date: 2026-07-29

## Changes

- Adds non-destructive, idempotent MCP annotations to `mc_create_watch_event` for managed non-interactive Workers.
- Parses structured steward decisions in synchronous Worker MCP assist.
- Sends only the decision `reply` into the Worker transcript.
- Keeps `escalate_human` pending for human review and does not send model JSON to the Worker.

## Validation

- Production 2.1.90 managed MCP baseline reached 2.441 seconds but exposed raw JSON in the transcript.
- Final production acceptance requires the same managed path to deliver plain semantic text within five seconds.

## Upgrade And Rollback

- Upgrade Center and Edge Runtime to 2.1.91. No database migration; Tray remains 3.0.10.
- Rollback to 2.1.90 is data-compatible.
