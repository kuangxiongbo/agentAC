# E-AgentCenter 2.1.31

Date: 2026-07-07

## Changes

- Fixes human-watch steward judging when the steward Agent repeatedly returns the same short reply, such as `继续`. Edge now treats a newly appended assistant message as a valid judge reply even when the text matches the previous reply.
- Keeps the 2.1.30 memory-assisted judging path; no schema migration.
- Server image contents: embeds Edge runtime `2.1.31`; tray native version remains `3.0.7`.

## Verification

- `pnpm exec vitest run src/lib/__tests__/human-watch-judge.test.ts src/lib/__tests__/memory-sync-search.test.ts` passed in `mission-control-client`.
- `pnpm run typecheck` passed in `mission-control-client`.
- Production gray validation on `2.1.30` confirmed the previous root cause moved from `no_session_kind` to `steward_judge_failed / Judge session returned empty reply`; this release fixes that Edge-side reply detection defect.

## Upgrade Notes

- Installed Edge clients must update to runtime `2.1.31` for the repeated-reply fix.
- Existing bindings do not need recreation.

## Rollback

- Roll back the 1Panel compose image tag to `agentcenter:2.1.30`, pull, and recreate `mission-control`.
- Runtime rollback follows the previous `edge-runtime` manifest bundled in the `2.1.30` image.

## Known Risks

- If the steward Agent actually produces no assistant message, the system still records `steward_judge_failed` and does not auto-send a fallback template.
