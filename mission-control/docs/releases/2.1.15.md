# AgentCenter 2.1.15 Release Notes

Date: 2026-06-19

## Changes

- Fixes duplicated human-watch agents in the central squad view by preserving a stable `local_agent_id` mapping across edge heartbeat, agent register, and bridge index ingestion.
- Keeps steward identity consistent between local and cloud: human-watch stewards now preserve `role=human-watch` and `agent_kind=human_watch` during upstream sync instead of being downgraded to generic agents.
- Adds automatic cleanup for historical duplicated `source='client'` agent mirrors, keeping the newest row for the same `client_id + local_agent_id`, with `client_id + original_name` as a fallback.
- Extends online/offline merge rules so bridge realtime rows and historical client mirrors collapse into a single visible card.
- Publishes Edge Web runtime `2.1.15`; tray native app remains `3.0.6`.

## Upgrade Notes

- Installed users do not need a new tray native build for this release; tray remains `3.0.6`.
- After deploying the new service image, let the local node heartbeat once or reconnect the tray so the duplicated historical mirrors can be reconciled and cleaned automatically.
- Use this release to validate two things together: duplicated watch stewards disappear from the squad view, and local/cloud human-watch labels stay consistent.
