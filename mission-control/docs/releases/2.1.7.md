# AgentCenter 2.1.7 Release Notes

Date: 2026-06-15

## Changes

- Adds visible first-start and runtime-upgrade progress in the tray setup window, including download percent, downloaded size, verification, unzip, replacement, validation, and local Web startup steps.
- Tightens installed-runtime upgrade behavior: when the service-center manifest requires a newer runtime, failed download or installation now surfaces as an error instead of silently starting the old runtime.
- Replaces Rust `Option` debug output in local Web version mismatch errors with a readable current-version and target-version message.
- Publishes Edge Web runtime `2.1.7` and tray app `3.0.2`.

## Artifacts

- Server image: `crpi-c9b9bml2ajb23n5d.cn-shenzhen.personal.cr.aliyuncs.com/1sheng/agentcenter:2.1.7`
- Edge runtime zip: `/edge-runtime/client-runtime-2.1.7-darwin-aarch64.zip`
- Tray DMG: `/edge-tray/e-agent-edge-3.0.2-darwin-aarch64.dmg`

## Upgrade Notes

- Existing installed users need the `3.0.2` tray update to see detailed first-start/runtime-download progress and the improved version-mismatch error.
- Existing runtime `2.1.6` users will install runtime `2.1.7` from the updated center manifest after production deployment.
- If runtime `2.1.7` download or checksum validation fails, the tray should stop with an actionable setup error rather than continuing on an older runtime.

## Verification

- `cargo check` in `mission-control-tray/src-tauri`
- `pnpm run verify:release-surfaces` after syncing docs, Edge runtime, and tray assets
- `pnpm run typecheck` in `mission-control`
- `pnpm run typecheck` in `mission-control-client`

## Known Risks

- The detailed progress UI is part of the native tray package; users running older tray versions will not see it until they install the new DMG.
- Installed-user end-to-end verification must be repeated after the production container is recreated, because the runtime manifest is served by the deployed image.
