# 2.1.93 - Goal Traceability And Memory Learning Recovery

Date: 2026-08-03

## Changes

- Requires every supervision plan task to declare the Goal success criteria it serves.
- Rejects plans with unknown criterion IDs or any uncovered Goal success criterion.
- Persists scheduled steward-memory extraction failures with attempt and retry metadata.
- Applies a 15-minute retry cooldown to scheduled extraction while keeping manual extraction immediately available.

## API And Data

- Plan task JSON adds required `goal_criteria: string[]` for newly submitted/generated plans.
- No database migration is required. Failure audits use the existing `supervision_events` table.
- Existing saved plans remain readable; replanning under 2.1.93 must use the new contract.

## Upgrade And Rollback

- Roll back to `agentcenter:2.1.92`; schema and existing records are data-compatible.
