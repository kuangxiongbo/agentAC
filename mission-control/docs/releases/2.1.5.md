# AgentCenter 2.1.5 Release Notes

Date: 2026-06-14

## Changes

- Fixes local Web chat state after continuing Codex/Claude sessions: once the continue request is accepted, the send button is no longer held by the background reply timer.
- Forces fresh transcript refresh after local session continue and repeats short follow-up refreshes, so completed replies appear without waiting for the long fallback poll.
- Clears optimistic user messages and waiting banners when the transcript already contains the assistant reply for the current turn.
- Keeps native tray app version at `3.0.0`; no tray binary update is required for this Web runtime fix.

## Installed User Upgrade

- Existing tray installations should update only the Web runtime from `2.1.4` to `2.1.5` after the deployed service advertises the new runtime manifest.
- Reusing `2.1.4` for this UI fix would not reliably notify installed users, because the tray compares manifest `client_version` with the installed runtime version.

- Local API validation confirmed the Codex reply exists in `/api/sessions/transcript`; the fix targets front-end waiting/refresh convergence.

## Rollback

- Roll back the server with the previous image tag and restart Compose/1Panel.
- If Edge runtime `2.1.5` causes issues, publish a newer fixed runtime version; do not reuse the same runtime version for changed code.
