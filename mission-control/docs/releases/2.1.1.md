# AgentCenter 2.1.1 Release Notes

Date: 2026-06-13

## Changes

- Restores the online subscription authorization app ID to `mission-control`, matching the existing user-center SKU `schema_app_id` and Zitadel application `business_app_id`.
- Keeps `agentCenter` as the product/application display name only, avoiding `app_instance_mismatch` when users enter from the existing subscribed SKU.
- Bumps server and Edge web runtime versions to 2.1.1. The native tray application remains 3.0.0.

## Artifacts

- Server image: `crpi-c9b9bml2ajb23n5d.cn-shenzhen.personal.cr.aliyuncs.com/1sheng/agentcenter:2.1.1`
- Edge runtime zip: `/edge-runtime/client-runtime-2.1.1-darwin-aarch64.zip`
- Tray DMG: `/edge-tray/e-agent-edge-3.0.0-darwin-aarch64.dmg`

## Upgrade Notes

- Deploy the new image and confirm `/api/license/config` reports `appId=mission-control`.
- Existing tray 3.0.0 installations should discover the 2.1.1 Edge runtime from the updated manifest after the production container is recreated.
- Roll back to `agentcenter:2.1.0` only if the user-center SKU/business binding is also migrated to `agentCenter`; otherwise 2.1.0 can continue to return `app_instance_mismatch`.
