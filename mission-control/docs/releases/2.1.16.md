# AgentCenter 2.1.16 Release Notes

Date: 2026-06-19

## Changes

- Adds a delete action for disconnected clients in Service Status. Operators can now remove an offline client after explicit confirmation.
- Deleting an offline client now also removes its mirrored client agents, bridge index cache rows, and synchronized session snapshots for that client.
- Client deletion is blocked when the client still owns active human-watch bindings, preventing accidental removal of bound stewards/workers.
- Central squad view no longer keeps unowned `client / bridge / bridge_index` historical entries in the main list when they have no active client identity, reducing long-lived “占位” noise.
- Publishes Edge Web runtime `2.1.16`; tray native app remains `3.0.6`.

## Upgrade Notes

- Installed users do not need a new tray native build for this release; tray remains `3.0.6`.
- After deploying the new image, use Service Status to remove disconnected clients that are no longer needed. Confirm with `delete-client-data` to clear their mirrored agents and synced session snapshots.
- If a disconnected client still has human-watch bindings, clear or migrate those bindings before deletion.

- Client cleanup currently targets mirrored `source='client'` agents and synced session snapshots. It does not delete user-created local agents or active human-watch bindings.
