# 2.1.62 - Atomic Edge Runtime Upgrade

Date: 2026-07-22

## Changes

- Tray Runtime installation and recovery now share one process-local install lock.
- A downloaded Runtime is copied, repaired and validated in an isolated candidate directory before the active Runtime is replaced.
- Activation keeps a rollback directory and restores it when post-activation validation fails.
- A healthy installed Runtime is no longer removed before the replacement package is ready.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.62`; native Tray: `3.0.9`.
- Installed users must update the native Tray to `3.0.9` to receive the concurrency and rollback fix; updating only the Web Runtime is insufficient.
- No database schema or HTTP API change. Rollback image is `2.1.61`; Tray rollback is `3.0.8` after restoring a valid Runtime directory.
