# 2.1.77 - Work Activity Agent Filter Compatibility

Date: 2026-07-24

## Changes

- Keeps the `2.1.76` global Work activity and session projection behavior.
- Maps a selected Bridge Agent's cloud-unique name back to `config.original_name` before applying the exact activity `actor` filter.
- Uses the same original name when matching local session keys while retaining the cloud Agent name for selection state and detail lookup.

## API And Compatibility

- `GET /api/activities` contracts and exact `actor` semantics are unchanged.
- The Activity UI now sends the correct local actor for `source=bridge_index` Agents and falls back to the display name for older/non-Bridge Agents.
- No database migration or configuration change is required.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.77`; native Tray remains `3.0.10`.
- Installed trays obtain Runtime `2.1.77` from the Center runtime manifest.
- Roll back Center and Runtime together to `2.1.76`.

## Verification

- Center and Edge typecheck, full test suites, production builds, packaged Runtime clean startup, and release surfaces passed for the underlying projection release.
- Production `2.1.76` proved local task create/update/delete and CLI session milestones; update appeared in about 1.8 seconds and delete in about 2.7 seconds.
- `2.1.77` Agent-filter UI verification remains a production release gate.

## Gray Release Risk

- Activity snapshots remain capped at 1000 combined milestones per Edge and report `truncated=true`.
- Live projection and Agent filtering require an online Edge; cloud control activity remains available during disconnects.
