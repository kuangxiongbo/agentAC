# 2.1.47 - Relational Supervision Isolation

Date: 2026-07-16

## User / Operator Changes

- Center legacy scheduling now excludes supervised tasks by both `metadata.goal_id` and the authoritative `supervision_goal_tasks.task_id` relation.
- The relational guard covers auto-route, assigned dispatch, stale requeue, Aegis review, and all task queue polling stages.
- Docker production builds remove `.next` before `next build` so stale incremental chunks cannot enter the image.
