# AgentCenter 2.0.6 Release Notes

Date: 2026-06-13

## Changes

- Aligns server, Edge web client, tray client, MCP server metadata, deployment examples, and download surfaces on version 2.0.6.
- Fixes subscription entitlement verification to use the user-center App ID `agentCenter` consistently.
- Hardens installed-user Edge runtime upgrades: the tray now checks the current server runtime manifest even when the local Web runtime is healthy, stops the old runtime, installs the newer verified runtime bundle, and restarts local service.
- Extends release-surface validation to fail on stale runtime, tray, login, MCP, and deployment version literals.

## Upgrade Notes

- Existing tray installations that run a compatible 2.0.6 tray can automatically discover and install newer Edge Web runtime bundles from the service center.
- Older tray installations should install the 2.0.6 DMG once to obtain the production runtime auto-update supervisor.
- Operators must publish both the immutable `2.0.6` image tag and `latest`; both tags should resolve to the same digest.
