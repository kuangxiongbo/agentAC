# 2.1.75 - Global Work Task Projection

Date: 2026-07-24

## Changes

- Adds the Bridge `task_snapshot` capability so the Center task board reads Work tasks from the live Edge Runtime, including unassigned tasks and status totals.
- Merges local runtime tasks with cloud supervision tasks. A local `remote_task_id` replaces the matching cloud row while retaining cloud project and supervision metadata.
- Adds stable client-scoped projection IDs and marks local tasks read-only in the cloud UI until reliable write-back is delivered.
- Refreshes the task board and Dashboard after a debounced Edge `task_snapshot_changed` notification. The notification carries no task content.

## API And Compatibility

- `GET /api/tasks` adds `authority`, `local_live`, `projection`, and per-task `source`/Edge identity fields.
- `GET /api/status?action=dashboard` uses the same merged task status counts.
- Edge clients without `task_snapshot` remain compatible and receive the existing cloud-only view.
- No database migration or configuration change is required.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.75`; native Tray remains `3.0.10`.
- Installed trays obtain Runtime `2.1.75` from the Center runtime manifest.
- Roll back Center and Runtime together to `2.1.74`.

## Verification

- Center typecheck and all `1156/1156` tests passed.
- Edge typecheck and all `1001/1001` tests passed.
- Center and Edge production builds passed; the packaged Runtime started from a clean directory and returned version `2.1.75`.
- Image manifest inspection and real production create/update/delete projection remain release gates.

## Gray Release Risk

- Task snapshots are capped at 1000 rows per Edge; `truncated=true` is exposed for larger local databases.
- Local projected tasks are intentionally read-only in the cloud UI until reliable ACK-based write-back is implemented.
- Public certificate-chain validation remains an infrastructure risk independent of this feature.
