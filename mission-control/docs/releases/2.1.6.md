# AgentCenter 2.1.6 Release Notes

Date: 2026-06-15

## Changes

- Fixes installed Edge users getting a browser-side crash or stale UI after upgrade when an orphaned old `next-server` keeps port `5101`.
- The tray now treats `/api/status` health as valid only when the running local Web version matches the installed runtime version. If a healthy but stale local Web process owns the port, the tray recovers it before starting the current runtime.
- Keeps the local CLI elevation toggle selected per session instead of resetting it after every message.
- Publishes Edge Web runtime `2.1.6` and tray app `3.0.1`.

## Upgrade Notes

- Existing installed users need the `3.0.1` tray update to get automatic stale-port recovery.
- Existing runtime `2.1.5` users will install runtime `2.1.6` from the updated center manifest after production deployment.
- Do not republish changed runtime code under `2.1.5`; installed trays compare manifest `client_version` with the local runtime version.

- macOS `rustfmt` is not installed in the local toolchain, so `cargo fmt` could not be run in this environment.
- Browser console still reports a blocked inline CSP warning from a non-critical inline script; Playwright did not observe a page-level runtime exception.
