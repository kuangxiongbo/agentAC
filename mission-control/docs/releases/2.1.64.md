# 2.1.64 - Edge Runtime Artifact Delivery

Date: 2026-07-22

## Changes

- Fixes the Docker build context allowlist so the advertised `2.1.64` Edge Runtime ZIP is embedded in the production image.
- Bounds Docker build concurrency and Node heap usage for resource-limited release hosts; runtime behavior is unchanged.
- Preserves all Human Watch, goal supervision, task, session synchronization, local mode and authorization behavior from `2.1.63`.
- No API, database migration or business-rule change is included.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.64`; native Tray remains `3.0.9`.
- Tray `3.0.9` downloads and atomically activates the Runtime. No native Tray reinstall is required.
- Roll back the center image and Runtime to `2.1.63` if the gray release fails.

## Verification

- Release surfaces, Server/Edge tests, typechecks and production builds must pass.
- The production Runtime URL must return a ZIP whose SHA-256 matches the manifest, not an HTML fallback page.
- Installed Runtime health must report `2.1.64`, include the Next app-route turbo runtime and reconnect its Bridge.
- Human Watch production acceptance still requires a real same-session Steward reply; this packaging fix does not pre-claim that result.

## Gray Release Risk

- Runtime ZIP embedding increases image size; verify free disk and container health before deployment.
- Keep the test Human Watch binding disabled except during bounded acceptance testing.
