# E-AgentCenter 2.1.26

Date: 2026-07-06

## Changes

- Raises the default human-watch auto-send limit from `6` to `60` successful interventions per binding per hour.
- Keeps the existing 30-second grace window and fingerprint dedupe, so repeated identical waits are still suppressed.
- Fixes the validation case where a Worker asks a sequence of confirmation questions and the steward stops after six successful replies.
- Server image contents: embeds Edge runtime `2.1.26`; tray native version remains `3.0.7`.
- API/data/config changes: no schema migration.

## Known Risks

- Higher auto-send capacity can increase steward LLM calls during long unattended Worker sessions. Operators can lower `max_interventions_per_hour` in tenant human-watch rules if a tenant needs stricter cost control.
