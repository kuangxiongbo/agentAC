# AgentCenter 2.1.12 Release Notes

Date: 2026-06-17

## Changes

- Strengthens tray runtime handover after a Web runtime download/update. If port `5101` is still occupied by an older E-Agent Edge runtime process, the tray now inspects the actual owning PID instead of relying only on the tracked child process handle.
- When the occupying process is confirmed to belong to E-Agent Edge (`cwd` under `~/.e-agent-edge/runtime`), the tray forcefully reclaims it and relaunches the target runtime.
- When the occupying process belongs to other software, the tray now refuses to kill it and returns a diagnostic that includes PID, process name, and working directory.
- Publishes Edge Web runtime `2.1.12` and tray native app `3.0.5`.

## Upgrade Notes

- Installed users must update the tray app to `3.0.5` to receive the stronger stale-process recovery logic.
- After deploying the new service image, runtime manifest `2.1.12` should be visible and the tray can replace the old local Web runtime.
