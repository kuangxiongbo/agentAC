# 2.1.42 - Steward Goal Supervision and Controlled Memory

Date: 2026-07-14

## User / Operator Changes

- Operators can create a supervised goal for an existing Human Watch steward, generate and approve a structured plan, dispatch tasks, and inspect execution, corrections, verification, and audit events.
- The steward can monitor Worker progress, request updates, correct direction, retry, reassign, request replanning, or escalate to a human.
- Controlled memories support candidate review, scoped retrieval, usage feedback, confidence adjustment, supersede, and expiry.

## Server Image Contents

- Server and embedded Edge Web runtime version: `2.1.42`.
- Native tray version remains `3.0.7`; no native tray rebuild is required.
- Docker tags: `agentcenter:2.1.42` and `agentcenter:latest`.

## Data / API / Migration Notes

- Migration `070_supervision_goals_and_memories` adds Goal, Plan, Goal Task, supervision event/lease, steward memory, and memory usage tables.
- New `/api/supervision/*` and `/api/steward-memories/*` APIs are operator/viewer protected and tenant scoped.
- Existing `tasks` and reliable `session.continue.requested` mailbox remain the execution facts and delivery path.

## Upgrade / Rollback

- Pull and recreate the server container. Existing Edge tray `3.0.7` downloads runtime `2.1.42` from the center manifest.
- Roll back with image `agentcenter:2.1.41`. Migration 070 is additive; retain the database and supervision records.

## Gray Release Risks

- Goal supervision is released for small-scope validation. Start with low-risk, bounded goals and require plan approval.
- Real model quality depends on the configured steward CLI/model and the evidence submitted by Workers.
- The 72-hour stability window starts after production deployment and is not complete at release time.
