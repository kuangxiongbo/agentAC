# E-AgentCenter 2.0.4

Released: 2026-06-13

E-AgentCenter 2.0.4 is a patch release for subscription entitlement consistency. It fixes the settings page refresh path so the displayed entitlements are read from the latest user-center verification result, and it accepts both current and compatible user-center response shapes.

## Fixed

- The license settings page now calls `/api/license/status?refresh=1` to clear the short-lived license verification cache before displaying entitlement values.
- License verification now accepts entitlements from either `license.entitlements` or top-level `entitlements`, preventing display mismatch when the user center response shape changes.
- `expiresAt` is also accepted from either `license.expiresAt` or top-level `expiresAt`.
- Edge runtime packaging now excludes historical `dist/edge-runtime-staging-*` directories from Next standalone tracing and fails packaging if `.next/static/chunks` is missing, preventing installed tray clients from serving CSS/JS requests as page HTML.

## Operator Notes

- If the user center subscription shows `enableLocalCliElevation: true`, the settings page should show `本地 CLI 提权：是` after refresh.
- If it still shows `否`, inspect the live `/api/license/status?refresh=1` response and the SKU entitlements stored in the user center.
- Installed tray clients running older runtime bundles may show an unstyled loading page if their local `~/.e-agent-edge/runtime/runtime/.next/static/chunks` directory is missing. Updating to the 2.0.4 Edge runtime bundle fixes the packaged static asset layout.
