# 2.1.76 - Global Work Activity Projection

Date: 2026-07-24

## Changes

- Adds the Bridge `activity_snapshot` capability so the Center activity feed reads bounded local Runtime activity and CLI session milestones.
- Merges local Runtime and cloud control events into one sorted, filtered, paginated feed and includes projected activity in stats.
- Adds stable client-scoped negative IDs plus explicit `local_runtime` and device labels without copying Edge activity into the cloud database.
- Refreshes the activity feed through a one-second throttled `activity_snapshot_changed` notification and Workspace-scoped SSE invalidation.

## API And Compatibility

- `GET /api/activities` adds `authority`, `local_live`, `projection_clients`, `projection_errors`, `projection_truncated`, and per-event source/Edge identity fields.
- Activity stats include recent online Edge events. Existing type, actor, entity, time, limit, and offset filters apply to the merged feed; `client_id` selects one Edge.
- Edge clients without `activity_snapshot`, offline clients, and timed-out clients remain compatible and receive cloud activity.
- No database migration or configuration change is required.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.76`; native Tray remains `3.0.10`.
- Installed trays obtain Runtime `2.1.76` from the Center runtime manifest.
- Roll back Center and Runtime together to `2.1.75`.

## Verification

- Center typecheck and all `1160/1160` tests passed.
- Edge typecheck and all `1002/1002` tests passed.
- Center and Edge production builds passed. Packaged Runtime startup, release-surface validation, image manifest inspection, and production event projection remain release gates.

## Gray Release Risk

- Each Edge snapshot returns at most 1000 combined activity/session milestones and reports `truncated=true` above that limit.
- Session milestones expose the latest bounded session metadata already available to the Runtime; activity history remains local authority and disappears from the live feed while Edge is offline.
- Local disk has limited free space; Docker publishing must not start below the documented 30 GiB release floor.
