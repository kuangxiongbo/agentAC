# 2.1.54 - Bounded Goal Evidence And Terminal Correction Guard

Date: 2026-07-16

## Changes

- `mc_get_supervision_goal` now returns schema 3 with complete event-type counts and a bounded recent-event window. Historical windowing is reported separately from transport truncation.
- Goal/task/event text is compacted so normal supervised Worker reads remain below the MCP output budget as audit history grows.
- Automatic corrections no longer continue tasks already in terminal `done` state. Independent verification remains responsible for judging completed evidence.
- No database migration is added. Existing Goals, tasks, messages, transcripts and audit events are retained.

## Production Root Cause

- Goal `abba41a2-9345-4c96-80b7-1645b16968b9` proved tasks 33 and 34 completed through Worker MCP and successors activated automatically.
- Task 35 stopped because the growing Goal response was visibly transport-truncated, as required by its safety constraint.
- A deleted 2.1.40-era container remained as orphan PID 3441525 and held the same SQLite volume as 2.1.53. Its old scheduler requeued task 35 and attempted OpenClaw every 60 seconds.
- The orphan process was terminated. Production now has one database writer, the current AgentCenter container only.
