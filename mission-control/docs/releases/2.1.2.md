# AgentCenter 2.1.2 Release Notes

Date: 2026-06-14

## Changes

- Rebuilds the Edge Web runtime bundle with complete Next.js compiled server runtime files, including `app-route-turbo.runtime.prod.js`.
- Strengthens native tray runtime validation so installed clients reject incomplete runtime directories that are missing `.next/static/chunks`, required Next runtime files, or matching package metadata.
- Rebuilds and republishes the native tray DMG as tray version 3.0.0 with verified internal macOS bundle metadata.
- Keeps authorization app ID behavior from 2.1.1: subscription validation uses `mission-control`; `agentCenter` remains only the user-facing app/instance display name.

## Artifacts

- Server image: `crpi-c9b9bml2ajb23n5d.cn-shenzhen.personal.cr.aliyuncs.com/1sheng/agentcenter:2.1.2`
- Edge runtime zip: `/edge-runtime/client-runtime-2.1.2-darwin-aarch64.zip`
- Tray DMG: `/edge-tray/e-agent-edge-3.0.0-darwin-aarch64.dmg`

## Installed User Upgrade

- Existing tray installations should discover runtime `2.1.2` from the service-center manifest and reinstall the downloaded Web runtime.
- Users who downloaded the previous `3.0.0` DMG should reinstall the republished `3.0.0` DMG if the app's macOS `Info.plist` still shows 2.x.
- Release validation must include the real user flow: download DMG from service center, install to `/Applications`, launch tray, wait for runtime download, and verify `http://127.0.0.1:5101/chat` loads CSS from `/_next/static` with `Content-Type: text/css`.
