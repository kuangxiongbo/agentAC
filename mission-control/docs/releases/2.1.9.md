# AgentCenter 2.1.9 Release Notes

Date: 2026-06-16

## Changes

- Fixes production CSP blocking client scripts on `/chat` by removing the fragile `strict-dynamic` production policy while retaining nonce and explicit script sources.
- Adds immediate session-send feedback in `/chat`: submitted, delivered, or direct runtime reply is visible without waiting for the transcript file to refresh.
- Keeps transcript fallback polling active even when SSE is connected, so lost lifecycle events cannot leave the chat view stale.
- Keeps the reply waiting loop alive after `prompt_completed` or bridge lifecycle events until transcript content proves the reply is complete.
- Adds the structured human-watch closure path: default steward-agent approval for normal risk, high-risk human-external approval, Worker human reply callback, Bridge sync, MCP tools, and audit records.
- Publishes Edge Web runtime `2.1.9`; tray native app remains `3.0.3`.

## Upgrade Notes

- Existing tray `3.0.3` users do not need a native tray reinstall for this release.
- Existing installed users receive runtime `2.1.9` from the updated service manifest after the production container is recreated.
- Operators must pull and recreate the production container so both the service UI and client download/update manifests point to `2.1.9`.
