# 2.1.73 - Legacy Work Identity Bridge Mapping

Date: 2026-07-24

## Changes

- Maps historical cloud Agent IDs to the current Bridge identity through `client_id + local_agent_id`.
- Keeps legacy Agent names as aliases so existing cloud supervision tasks remain visible after the identity switches to Edge authority.
- Prevents an Agent detail page opened while Edge was offline from remaining on `authority=cloud` after Bridge reconnects.
