# AgentCenter 2.1.3 Release Notes

Date: 2026-06-14

## Changes

- Fixes local Web CLI elevation entitlement checks for installed Edge clients by separating `edge.enroll_token` from `gateway.token`.
- Allows the center `/api/local-cli/elevation-entitled` endpoint to resolve the real user and tenant from a scoped Edge enroll token before checking `enableLocalCliElevation` online.
- Hardens Bridge WebSocket authentication: production bridge connections require a configured token unless `MC_BRIDGE_ALLOW_ANONYMOUS=1` is explicitly set.
- Publishes Edge Web runtime `2.1.3`; installed users require a higher `client_version` in the service-center runtime manifest to receive the update.
- Keeps native tray app version at `3.0.0`; this release updates tray bootstrap/config behavior but does not require a tray version bump beyond 3.0.0.

## Installed User Upgrade

- Existing tray installations must discover runtime `2.1.3` from the deployed service-center `/api/releases/edge-runtime-manifest`.
- Rebuilding a changed runtime under an existing version is not sufficient: the tray treats the installed runtime as current when the manifest `client_version` matches the local runtime version.
- Production validation must happen after deploying the new service image, then downloading/updating from the real service-center manifest.

- If Edge runtime `2.1.3` causes issues, publish a newer fixed runtime version; do not reuse the same runtime version for changed code.
