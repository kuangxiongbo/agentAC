# 2.1.52 - Managed Worker Identity Across Continuations

Date: 2026-07-16

## Changes

- Managed `mc_continue_session` calls now carry process-bound Worker/session context into the next turn without exposing identity fields as tool arguments.
- Edge accepts that context only for API-key requests whose Worker session exactly matches the target session; browser cookie requests cannot elevate themselves with hidden fields.
- `mc_list_sessions` and `mc_session_transcript` are declared read-only, non-destructive, idempotent and closed-world. Session pause/terminate controls retain their approval boundary.
