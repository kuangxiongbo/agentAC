# 2.1.68 - Edge Runtime Fallback Protection

Date: 2026-07-23

## Changes

- Prevents an incomplete local standalone fallback from overwriting a valid Runtime after a post-install error.
- Requires fallback content to be completed, validated in a candidate directory, and atomically activated.
- Adds clean ZIP extraction and real Runtime health startup to the packaging gate.
- Serializes Tray process lifecycle checks and spawn so setup and supervision cannot race on port `5101`.
- Removes the legacy KeepAlive Runtime LaunchAgent during Tray startup to establish one Node process owner.

## Artifacts And Upgrade

- Center image and Edge Web Runtime: `2.1.68`; native Tray: `3.0.10`.
- Installed users must update the native Tray so the protected fallback path is active, then install Runtime `2.1.68`.
- No database migration is included. Roll back to image/Runtime `2.1.67` and Tray `3.0.9`; preserve Edge and Center SQLite backups before task recovery.

## Verification

- Rust Runtime focused tests include incomplete fallback preservation.
- Runtime packaging must pass clean extraction, required Next files, native ABI, real startup, and health version checks.
- Production acceptance requires local `5101` health, Bridge reconnection, one recovered Goal task dispatch, a new Worker transcript turn, and completion only after CLI return.

## Gray Release Risk

- Existing false-running Goal tasks are repaired only after the upgraded Edge is online; historical state is not mutated automatically.
