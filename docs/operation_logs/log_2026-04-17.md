# Operation Log - 2026-04-17

## User Intent
1.  **架构切换**: 明确 Mission Control Server (5000) 为中央网关，OpenClaw 为其中的一种智能体框架。
2.  **通用监控**: 支持不同类型 Agent (Claude, Cursor, CodeX, OpenClaw 等) 的上报与识别。
3.  **流程规范**: 要求建立“文档先行”和“操作日志”的 Skill。

- [x] **基础设施**: 在根目录创建 `docs/` 体系，包含 `system_architecture.md` 和 `workflow_skill.md`。
- [x] **数据库变更**: 
    - 新增 `framework` 字段 (Migration 052)。
    - 新增 `parent_id` 字段 (Migration 053)，支持 OpenClaw 子智能体结构。
- [x] **后端适配**: 更新 `mission-control-client` 的 `POST /api/agents` 逻辑：

    - 仅对 `openclaw` 类型执行本地 Provisioning (ENOENT 错误规避)。
- [x] **前端增强**: 
    - `CreateAgentModal` 新增“Step 0: Choose Framework”步骤。
    - `AgentSquadPanelPhase3` 的智能体卡片新增 `framework` 标签显示。
- [x] **Type 定义**: 服务端/客户端同步更新了 `Agent` 接口、Zod Schema 和 Store 定义。
- [x] **数据同步 (Bridge)**: 
    - 更新 `remote-server-bridge.ts` 使其在握手和心跳时发送 `framework` 和 `parent_id`。
    - 更新服务端 `bridge-server.ts` 以正确持久化从客户端接入的新增字段。
- [x] **Store 幂等修复**: 修复 `addAgent` 的重复添加逻辑，解决用户反馈的“添加一个出现两个”的问题。
- [x] **UI 聚合显示**: 
    - 实现了按 **Framework** (外层) 进行分组展示。
    - 实现了按 **Parent/Child** (内层) 嵌套展示子智能体，完美适配 OpenClaw 及其子 Agent 结构。
    - 在 5000 服务端与 5001 客户端同步完成了此 UI 重构。
- [x] **智能体创建向导增强**: 
    - 实现了**配置动态化**：根据 Step 0 选择的 Framework，Step 2 的配置项会自动切换。
    - **OpenClaw 类型**：保留完整的模型梯队、沙箱模式、网络配置等高级编排项。
    - **非 OpenClaw 类型**：隐藏冗余的 OC 专属配置，显示“框架特定元数据”配置（如外部 Session/API Ref），防止配置混淆。
    - **层级关系支持**：在创建阶段新增“父智能体 (Parent Agent)”选项，支持直接建立 Agent 树状结构。
    - **审核逻辑优化**：仅在选择 OpenClaw 时显示“同步至网关”和“自动化部署”选项。
- [x] **术语标准化 (Terminology)**: 全局更新 `messages/zh.json`，将“代理” (Proxy) 统一为“智能体” (Agent)，确保符合胡 (Hub) 的定位。
- [x] **多语言自动补全 (L10n)**: 补全了 `zh.json` 和 `en.json` 中缺失的 `agentDetail.*` 翻译键，解决了用户截图中显示的原始键名渲染问题。
- [x] **向导流程重构 (Wizard Redesign)**: 
    - 实现了全新的 **3 步骤通用向导**：Step 0 (身份与框架)、Step 1 (角色与层级)、Step 2 (技术配置)、Step 3 (审核与部署)。
    - **UI/UX 升级**：采用了更精美的 UI 布局、框架图标区分、进度流程动画以及更语义化的配置分组。
    - **容错增强**：改进了错误处理逻辑，现在能直接在向导中显示服务器返回的 Zod 校验详细错误 (details)，方便调试。
- [x] **数据校验健壮化 (Schema)**: 
    - 修复了 `parent_id` 校验失败的问题，允许其为 `null` (无上级) 或 `undefined`。
    - 放宽了 `openclaw_id` 的校验规则，允许通过空字符串自动生成，提升了用户体验。
