# Edge Runtime 2.1.31 Release Notes

Date: 2026-07-07

## Changes

- Fixes Codex-based human-watch steward judge reply detection. Repeated short replies like `继续` are now accepted when they are newly appended assistant messages, instead of being mistaken for the previous baseline reply.
- Keeps Bridge memory search support introduced in `2.1.30`.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.31-darwin-aarch64.zip`
- Tray DMG: unchanged native tray `3.0.7`; existing tray users should receive only the Web runtime update.

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.31`.
2. Existing tray `3.0.7` users should update the Web runtime automatically.
3. After update, `http://127.0.0.1:5101/api/status?action=health` should report version `2.1.31`.

## Verification

- `pnpm exec vitest run src/lib/__tests__/human-watch-judge.test.ts src/lib/__tests__/memory-sync-search.test.ts` passed.
- `pnpm run typecheck` passed.

## Known Risks

- The fix only accepts newly appended assistant messages. If the runtime fails to append any assistant message, the center still correctly treats the judge attempt as failed.
