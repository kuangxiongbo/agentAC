# Edge Client 2.1.4 Release Notes

Date: 2026-06-14

## Changes

- Fixes local Web `Failed to fetch` symptoms caused by opening or refreshing large Codex history sessions.
- Codex session list scanning now reads bounded windows for large JSONL files instead of loading the full file.
- Keeps transcript loading paged so very large Codex sessions remain responsive.
- Cleans runtime packaging by excluding development logs, pid files, `.next/cache`, `.DS_Store`, and macOS resource metadata.
- Keeps tray app version at `3.0.0`; the Web runtime version is `2.1.4`.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.4-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.0-darwin-aarch64.dmg`

## User Flow Validation

The required validation path is production-like:

1. Deploy the service image that advertises runtime `2.1.4`.
2. Launch an installed tray with an older runtime.
3. Let it fetch `/api/releases/edge-runtime-manifest` from the service center.
4. Confirm the installed runtime package version becomes `2.1.4`.
5. Open `http://127.0.0.1:5101/chat` and select a large Codex session.
6. Confirm `/api/sessions`, `/api/sessions/transcript`, `/api/server-bridge`, normal send, and elevated send remain responsive.
