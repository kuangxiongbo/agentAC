# 2.1.49 - Supervision MCP Approval Metadata

Date: 2026-07-16

## Edge Changes

- `mc_get_supervision_goal` is declared read-only, non-destructive, idempotent and closed-world.
- `mc_complete_supervision_task` is declared non-destructive, idempotent and closed-world while remaining a write operation.
- `tools/list` now returns each supervision tool's annotations to Codex.

## Verification

- A real non-interactive Codex exec with `approval_policy=never` successfully called the annotated Goal read tool.
- The annotated completion tool reached the center API instead of returning `user cancelled MCP tool call`; the failed-Goal diagnostic was rejected by the API state guard as expected.
- Managed Worker/session identity remains process-bound and cannot be overridden by model arguments.
- Focused Edge tests passed: 2 files / 4 tests. The full Edge suite passed: 89 files / 953 tests, and typecheck passed with a single Node process using a 10 GiB old-space limit.
- The clean Runtime production build passed. `client-runtime-2.1.49-darwin-aarch64.zip` has SHA-256 `bcbbb7f172c472f0b2a3f78e895c64242ad45c3ea3e9642cbfd10b69a5f3ae21`.

## Upgrade

- Tray remains 3.0.8 and does not require a native application update.
- Installed clients must replace their Web Runtime with 2.1.49 and verify the local health endpoint reports `version=2.1.49` before running the supervision closure test.

## Known Risk

- Tray 3.0.8 automatic Runtime replacement can enter concurrent fallback copies after removing the old Runtime. The 2.1.49 installed-user test must verify a single listener and may use a SHA-verified manual restore if automatic replacement fails.
- Failed Goal `0bbcfe7f-a4ee-449c-8ccc-f2f4a42253ad` remains audit evidence and must not count as closure success.
