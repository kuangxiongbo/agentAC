# Edge Client 2.1.8 Release Notes

Date: 2026-06-15

## Changes

- The tray now treats a healthy `5101` process as valid only when its health version matches the installed runtime version.
- Stale local Web processes left from older runtime versions are automatically recovered before the current runtime is started.
- Runtime download progress includes byte counts in the visible setup message.
- Closing the setup window hides it and keeps the tray/local Web service running; explicit tray Quit remains the only normal user path that stops the local Web process.
- Includes the `2.1.8` Web runtime and tray `3.0.3`.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.8-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.3-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.8`.
2. Existing tray users should update to tray `3.0.3`.
3. After deployment, installed Web runtime should update from `2.1.7` to `2.1.8`.

## Verification

- `pnpm run typecheck`
- `cargo check` in the tray Tauri project
- Release-surface verification after runtime and tray bundles are synced
