# 2.1.68 - Safe Runtime Recovery

Date: 2026-07-23

## Changes

- Packages are now cleanly extracted and started against the health API before release.
- Tray `3.0.10` validates local standalone fallback content before atomic activation.
- A valid downloaded Runtime is retained when only a later metadata step fails.
- Tray process lifecycle operations are serialized to prevent duplicate `5101` startup attempts.
- Tray startup retires the legacy Runtime LaunchAgent that could repeatedly contend for port `5101`.

## Upgrade

- Update the native Tray to `3.0.10`, then allow it to install Edge Web Runtime `2.1.68` from the Center manifest.

## Verification

- Runtime installer Rust tests and package shell validation pass.
- Clean package startup must return version `2.1.68` from `/api/status?action=health`.

## Gray Release Risk
