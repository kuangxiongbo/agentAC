# Edge Runtime 2.1.19 Release Notes

Date: 2026-07-05

## Changes

- Added local reliable Mailbox inbox/outbox for cloud-to-Edge messages.
- Added `/api/local/mailbox/drain` and `/api/local/mailbox/status`.
- Added `human_watch.assist.requested` execution: read Worker transcript, call steward judge, then continue the Worker session.
- Added reliable handlers for `session.continue.requested` and `permission.decision.requested`.
- Added ack/fail outbox sync so Edge restarts can recover unfinished mailbox work.
- Updated Bridge capability reporting with `reliable_mailbox`, `human_watch_assist_v2`, `permission_decision_relay`, and `serial_session_continue`.

## Upgrade Notes

Installed Edge/tray users need the 2.1.19 runtime bundle before production enables queued human-watch assist for their client. Old clients can still use the legacy synchronous Bridge path, but they cannot drain cloud queued messages.

## Risks

- Queued assist requires the cloud server to enable `MC_RELIABLE_EDGE_MESSAGES=1` and the client to advertise `reliable_mailbox`.
- Local runtime must remain reachable on the tray-managed port so the tray can trigger drain after startup or recovery.
