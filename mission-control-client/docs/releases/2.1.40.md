# 2.1.40 - Human Watch Fast Stewarding

Date: 2026-07-08

## User / Operator Changes

- New local Human Watch steward agents default to 5 second idle detection and zero grace after prompt.
- Existing steward agents can be updated through synced center rules or local config refresh.
- Explicit Worker instructions such as `回答后说"确认"` are classified by the center as answer-required waits; the steward Agent should answer the question first, then include confirmation.
- Binding controls synced from the center can configure automatic stop conditions so validation runs do not continue indefinitely.

## Edge Runtime Contents

- Edge Web runtime version: `2.1.40`.
- Native tray version is unchanged.
- Runtime package is embedded in the `2.1.40` center image and advertised by the Edge runtime manifest.
