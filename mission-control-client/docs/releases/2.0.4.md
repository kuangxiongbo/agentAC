# E-AgentCenter Client 2.0.4

Released: 2026-06-13

E-AgentCenter Client 2.0.4 aligns with the server patch release for subscription entitlement consistency.

## Changed

- Version aligned with server and tray release `2.0.4`.
- Edge runtime packaging excludes stale historical staging directories and verifies `.next/static/chunks` before publishing the runtime zip.

## Operator Notes

- Existing installations that still run `v2.0.1` should update to the 2.0.4 runtime bundle so `/_next/static/*` requests resolve to CSS/JS files instead of the catch-all page route.
