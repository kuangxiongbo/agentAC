# Edge Runtime 2.1.22 Release Notes

Date: 2026-07-06

## Changes

- Rebuilt the Edge runtime with the tray-compatible Node 22 ABI.
- Added release packaging protection so a developer shell using Node 25 cannot publish an incompatible `better-sqlite3` native module.
- Includes the 2.1.21 fix that preserves existing `mc-edge-*` client ids during local bootstrap.
- Includes the 2.1.20 human-watch steward judge fix: historical steward agents without a pre-existing judge session can auto-provision and answer mailbox assist requests.
- Artifact: `client-runtime-2.1.22-darwin-aarch64.zip`.
- SHA-256: `fb7595ffa194a12ab516fe65f6957eb0b7ceefc46431764a29f8fa4b462d9c3c`.

## Upgrade Notes

- Installed tray users do not need a tray DMG update for this release; the tray should fetch the new Edge runtime after the server manifest is published.
- Runtime install target is `~/.e-agent-edge/runtime`, with `runtime/package.json` version `2.1.22`.
- Existing clients using `mc-edge-*` ids should keep the same id across restart and runtime refresh.

## Verification

- `package-edge-runtime.sh` checks ABI `127` before build and validates staged `better-sqlite3` before zip output.
- `pnpm vitest run src/lib/__tests__/edge-local-bootstrap.test.ts src/lib/__tests__/human-watch-judge.test.ts src/lib/__tests__/local-mailbox-human-watch-assist.test.ts` passed under Node `v22.16.0` ABI `127`.
- `NODE_OPTIONS=--max-old-space-size=8192 pnpm exec tsc --noEmit --pretty false` passed under Node `v22.16.0`.
- Installed-runtime smoke test started the packaged runtime with Node `v22.16.0` and returned health version `2.1.22`.

## Rollback

- Repoint the server Edge runtime manifest to the previous runtime, or roll the server image back to `agentcenter:2.1.21`.
- Existing tray clients will fetch the manifest target on the next runtime update check.

## Known Risks

- Automatic tray update validation depends on production manifest availability. Before the 2.1.22 image is deployed, tray clients still see the current production runtime manifest.
