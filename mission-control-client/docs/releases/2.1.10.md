# Edge Client 2.1.10 Release Notes

Date: 2026-06-17

## Changes

- Fixes local platform-managed Codex startup by emitting `mcp_servers.mission_control.env` as a TOML map instead of a JSON string.
- Adds local MCP aliases/tools `mc_create_watch_event` and `mc_record_worker_human_reply`, matching the server-side managed-session contract.
- Updates the bundled Web runtime to `2.1.10`.
- Updates the tray native app to `3.0.4`, including automatic recovery of stale owned runtime processes on port `5101`.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.10-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.4-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.10` and tray `3.0.4`.
2. Existing tray `3.0.3` users should install tray `3.0.4` to receive the stale-process auto-recovery fix.
3. After deployment and tray relaunch, installed Web runtime should update to `2.1.10`.
