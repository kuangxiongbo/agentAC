# Edge Client 2.1.6 Release Notes

Date: 2026-06-15

## Changes

- Keeps the local CLI elevation button selected per session after sending a message, page refresh, or session switch.
- Fixes upgrade reliability when an old local Web process is still listening on port `5101`; tray `3.0.1` can detect the stale version and restart the current runtime.
- Includes the `2.1.6` Web runtime for installed Edge users.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.6-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.1-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.6`.
2. Existing tray users should update to tray `3.0.1` to receive stale-port recovery.
3. After tray update, installed Web runtime should update from `2.1.5` to `2.1.6`.

## Verification

- `pnpm run typecheck`
- Local `/chat` Playwright smoke verified no page-level exception.
- Local elevation preference persisted through browser reload via session-scoped local storage.
