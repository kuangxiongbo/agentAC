# Edge Client 2.1.14 Release Notes

Date: 2026-06-19

## Changes

- Runtime package version moves to `2.1.14` so installed users can receive the service-advertised human-watch event loop updates.
- Local Web runtime now supports the platform-driven watch-event callback path used by Worker session replies and permission resolution.
- Tray native app remains `3.0.6`; no new DMG is required for this release.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.14-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.6-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.14` and tray `3.0.6`.
2. Existing installed trays should detect the higher runtime manifest version and replace the local Web runtime automatically.
3. If a host remains on the old runtime after deployment, relaunch the tray once and confirm `http://127.0.0.1:5101/api/status` reports `2.1.14`.

## Verification

- `pnpm exec tsc --noEmit --pretty false`
- Runtime manifest advertises `client_version=2.1.14`
- Real local session callback verified through `send_message_to_worker`
