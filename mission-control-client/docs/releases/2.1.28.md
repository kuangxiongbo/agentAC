# Edge Runtime 2.1.28 Release Notes

Date: 2026-07-06

## Changes

- Keeps the Edge runtime package version aligned with the 2.1.28 center release.
- No Edge runtime behavior change is required for the server-side human-watch 24-hour throttle window.

## Verification

- Runtime package must be built with Node `v22.x` ABI `127`.

## Rollback

- Repoint the server Edge runtime manifest to `2.1.26`, or roll the server image back to `agentcenter:2.1.26`.
