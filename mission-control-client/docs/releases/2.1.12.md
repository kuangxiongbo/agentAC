# Edge Client 2.1.12 Release Notes

Date: 2026-06-17

## Changes

- Tray native app `3.0.5` improves recovery when an old local Web runtime still owns port `5101` after an update.
- The tray now distinguishes E-Agent Edge stale runtime processes from unrelated software before deciding whether to terminate the occupying process.
- Runtime package version moves to `2.1.12` so installed users can receive the updated service-advertised runtime.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.12-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.5-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.12` and tray `3.0.5`.
2. Install tray `3.0.5` so the stronger `5101` stale-process recovery path becomes active.
3. After relaunch, the tray should reclaim the stale E-Agent Edge runtime PID and start the new runtime automatically.
