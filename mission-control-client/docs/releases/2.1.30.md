# Edge Runtime 2.1.30 Release Notes

Date: 2026-07-07

## Changes

- Adds Bridge handling for `memory_search_request`, allowing the center to retrieve bounded local memory snippets for human-watch steward judging.
- Adds local memory search over OpenClaw sqlite memory `chunks` tables, with fallback to the existing file-memory FTS search.
- Improves Chinese phrase matching for local memory search by generating short Han-character fragments instead of relying only on whitespace tokens.
- Aligns watch-event card labels with the center UI, including structured context and transcript summary labels.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.30-darwin-aarch64.zip`
- Tray DMG: unchanged native tray `3.0.7`; existing tray users should receive only the Web runtime update.

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.30`.
2. Existing tray `3.0.7` users should update the Web runtime automatically.
3. After update, `http://127.0.0.1:5101/api/status?action=health` should report version `2.1.30`.

## Verification

- `pnpm exec vitest run src/lib/__tests__/memory-sync-search.test.ts` passed.
- `pnpm run typecheck` passed.
- Release-surface verification must pass after Edge runtime and project docs are synced into `mission-control/public/`.

## Known Risks

- Memory-assisted replies depend on actual local memory content. Empty memory stores will produce no memory context, but normal human-watch judging continues.
