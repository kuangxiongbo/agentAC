# Edge Client 2.1.16 Release Notes

Date: 2026-06-19

## Changes

- Runtime package version moves to `2.1.16` so installed users receive the central cleanup and disconnected-client handling updates through the service-advertised runtime bundle.
- Tray native app remains `3.0.6`; no new DMG is required for this release.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.16-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.6-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.16` and tray `3.0.6`.
2. Existing installed trays should detect the higher runtime manifest version and replace the local Web runtime automatically.
3. After relaunch, disconnected clients can be removed from the center, and their mirrored client agents should no longer continue occupying the main squad view.

## Verification

- Runtime manifest advertises `client_version=2.1.16`
- Service Status delete action works for disconnected clients
