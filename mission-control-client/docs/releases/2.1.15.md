# Edge Client 2.1.15 Release Notes

Date: 2026-06-19

## Changes

- Runtime package version moves to `2.1.15` so installed users receive the steward identity and duplicate-agent cleanup fixes from the server-advertised runtime bundle.
- Upstream sync now preserves `human-watch` steward role and `agent_kind=human_watch` instead of normalizing the steward into a generic agent.
- Heartbeat and register payloads now include `local_agent_id`, allowing the center to map one local steward to one central row and clean historical duplicate mirrors.
- Tray native app remains `3.0.6`; no new DMG is required for this release.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.15-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.6-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.15` and tray `3.0.6`.
2. Existing installed trays should detect the higher runtime manifest version and replace the local Web runtime automatically.
3. After relaunch or one successful heartbeat, duplicated watch stewards should collapse to a single row and keep the watch label in both local and cloud views.
