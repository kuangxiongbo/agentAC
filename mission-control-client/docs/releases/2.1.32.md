# 2.1.32

Date: 2026-07-07

## Changes

- Runs human-watch steward Judge prompts with a dedicated 10-minute local CLI timeout instead of the generic 180-second session timeout.
- Prevents duplicate steward Judge requests for the same local Agent from being queued while a prior Judge is still running.
- Increases RemoteBridge heartbeat tolerance to reduce false disconnects during long-running steward/model work.
- Preserves 2.1.31 behavior that treats repeated short replies such as `继续` as valid when a new assistant message was added.
