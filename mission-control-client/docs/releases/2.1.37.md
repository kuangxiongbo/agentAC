# 2.1.37 - Human Watch Judge Runtime Error Guard

Date: 2026-07-08

## User / Operator Changes

- Edge Human Watch judge now rejects runtime error output instead of returning it as a steward reply.
- Recognized failures include missing model environment variables, API errors, authentication failures, and local CLI command failures.
- This prevents the center from auto-sending local runtime errors into Worker sessions.

## Runtime / Tray Notes

- Edge Web runtime package version: `2.1.37`.
- Native tray version is unchanged.
- Installed Edge runtimes should update to `2.1.37` to get the judge output guard.

## Verification

- `pnpm --dir mission-control-client test src/lib/__tests__/human-watch-judge.test.ts`.
- `pnpm --dir mission-control-client exec tsc --noEmit`.
- Center release surface verification checks the embedded Edge runtime manifest and artifact hash.

## Gray Release Risks

- The guard prevents bad auto-send behavior, but it does not solve missing credentials in the local Edge process. Configure the local runtime environment or use a steward Agent backed by an available CLI provider.
