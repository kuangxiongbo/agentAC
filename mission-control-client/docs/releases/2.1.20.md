# Edge Runtime 2.1.20 Release Notes

Date: 2026-07-05

## Changes

- Human-watch steward judge now uses bound local-agent execution, so a steward with no `session_key` automatically provisions a dedicated judge session before replying.
- Existing invalid or stale steward sessions can be re-provisioned by the same execution path instead of failing mailbox processing.
- Runtime packaging now rebuilds and verifies `better-sqlite3` before publishing the runtime zip, catching Node ABI mismatches before installed clients download the bundle.

## Verification

- `pnpm vitest run src/lib/__tests__/human-watch-judge.test.ts src/lib/__tests__/local-mailbox-human-watch-assist.test.ts src/lib/__tests__/human-watch-steward.test.ts`
- `NODE_OPTIONS=--max-old-space-size=8192 pnpm exec tsc --noEmit --pretty false`

## Upgrade Notes

Installed Edge/tray users need runtime `2.1.20` for queued human-watch assist to work with historical steward agents that were created before dedicated judge session provisioning was reliable.

## Risks

- First assist after upgrade may take longer because the steward judge session can be provisioned on demand.
- The local machine must have the configured CLI runtime authenticated and available for the steward framework.
