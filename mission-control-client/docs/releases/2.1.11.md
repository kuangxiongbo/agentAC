# Edge Client 2.1.11 Release Notes

Date: 2026-06-17

## Changes

- The service download flow now distinguishes Apple Silicon and Intel Mac tray downloads instead of presenting one generic Mac installer.
- The download API returns structured multi-platform tray download entries so the UI can show availability per chip family.
- Runtime package version moves to `2.1.11` to ensure installed users receive the new service-advertised client metadata.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.11-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.4-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.11`.
2. Apple Silicon users continue to download the existing `3.0.4` tray DMG.
3. Intel Mac users now see a separate entry, but the actual Intel tray/runtime artifacts are still pending.
