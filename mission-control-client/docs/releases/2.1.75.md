# 2.1.75 - Edge Work Task Snapshot Runtime

Date: 2026-07-24

## Changes

- Advertises the Bridge `task_snapshot` capability and returns bounded local task rows plus complete status totals.
- Parses task tags and metadata before transport and includes local project context.
- Debounces local task lifecycle events for 250 ms, refreshes Agent task summaries, and sends a content-free snapshot invalidation signal to the Center.

## Upgrade

- Native Tray remains `3.0.10` and installs Runtime `2.1.75` from the Center manifest.
- No local database migration or user configuration change is required.

## Verification

- TypeScript and all `1001/1001` Edge tests passed, including a protocol-level task snapshot response test.
- Production build passed; the packaged Runtime started from a clean directory and returned version `2.1.75`.

## Gray Release Risk

- Each snapshot returns at most 1000 tasks and reports `truncated=true` above that limit.
- A disconnected Edge cannot provide live task content; the Center keeps cloud control data available.
