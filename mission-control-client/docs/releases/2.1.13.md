# Edge Client 2.1.13 Release Notes

Date: 2026-06-17

## Changes

- Tray native app `3.0.6` now terminates the full local Web process group on macOS instead of only the tracked child handle.
- This prevents `caffeinate`/`next-server` leftovers from keeping port `5101` occupied after a runtime update or restart.
- Runtime package version moves to `2.1.13` so installed users can receive the updated service-advertised runtime metadata.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.13-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.6-darwin-aarch64.dmg`

## Upgrade Notes

1. Deploy the service image that advertises runtime `2.1.13` and tray `3.0.6`.
2. Install tray `3.0.6` so the process-group shutdown path becomes active.
3. After relaunch, stale local Web process trees should no longer survive a tray-driven restart.
