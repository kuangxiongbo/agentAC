# 2.1.67 - Completion-Aware Reliable Mailbox

Date: 2026-07-23

## Changes

- Keeps reliable session continuation and Human Watch assist messages processing until the Worker CLI turn actually completes.
- Reports CLI failures through the reliable fail path with the real error instead of acknowledging enqueue success.
- Preserves per-session serialization and exposes completed Worker reply summaries for Center audit.

## Upgrade

- Edge Web Runtime updates to `2.1.67`; native Tray remains `3.0.9` and uses its existing atomic Runtime updater.

## Verification

- Full Edge suite: 999/999 passed; mailbox and local executor focused tests: 25/25 passed.
- TypeScript and production Runtime build passed under the packaged Node 22 ABI.

## Gray Release Risk

- A long CLI turn keeps the mailbox drain request open until completion; Center leases remain idempotent and may be re-leased by the same client while execution is active.
