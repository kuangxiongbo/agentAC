# Edge Client 2.1.2 Release Notes

Date: 2026-06-14

## Changes

- Repackages the Edge Web runtime with complete Next.js compiled server runtime files required by standalone API routes.
- Adds packaging hard gates for `.next/static/chunks` and required Next runtime files so the tray cannot install a visually broken or server-incomplete runtime.
- Keeps the native tray app version at 3.0.0, but republishes the DMG with verified internal macOS bundle version metadata.

## Artifacts

- Edge runtime zip: `client-runtime-2.1.2-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-3.0.0-darwin-aarch64.dmg`

## User Flow Validation

Validated release candidates must be tested exactly as an installed customer would use them: download DMG from the service center, install the app, launch the tray, allow it to download the runtime, then open `http://127.0.0.1:5101/chat` and verify CSS/JS are served from `/_next/static` instead of falling back to HTML.
