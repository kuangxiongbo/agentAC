# Edge Client 2.0.5 Release Notes

Release date: 2026-06-13

## What Changed

- Aligned Edge web, tray, and server release version to 2.0.5.
- Added release-time verification that the packaged runtime includes `.next/static/chunks`, preventing the local web UI from opening without styles or JavaScript.
- Ensured download/update manifests and package SHA-256 values are verified before the server image is published.

## Included Artifacts

- Edge runtime zip: `client-runtime-2.0.5-darwin-aarch64.zip`
- Tray DMG: `e-agent-edge-2.0.5-darwin-aarch64.dmg`

## Upgrade Notes

- New downloads from the server download page should show 2.0.5.
- Installed tray clients can discover the 2.0.5 manifest after the server image is deployed.
